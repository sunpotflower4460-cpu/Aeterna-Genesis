モデルと経路の証明

立方周期格子の間隔と kBT を1とし、各サイトは空き、I、B、F、W のいずれかを取る。
I と B は同じ材料分子の二つの状態で、F と W は別の分子の二つの状態である。
結合エネルギーは H = df N_B + ε N_BB。B–B の最近接対は一度だけ数える。
受動経路は B ⇄ I、燃料を含む経路は最近接サイト i,j の B_i + F_j ⇄ I_i + W_j。
各局所遷移の速度比は exp(-ΔH)。交換サイトの空き ⇄ F/W の速度比は z_F、z_W。
同じ n_B に対し、疎な実装は非B近傍 z−n_B 個から相手を一様選択し、候補速度を
元の (z−n_B)/z 倍にする。許される一対の実効速度は元と等しい。z=6。
両実装の時計は連続時間の指数待ち時間。記録は10時間単位ごとで、積分刻みは無い。
局所式の検証には既存の対詳細釣り合い試験、微小格子の平衡分布、絶対時計を使った。

正味の B→I 回数を受動 Jp、燃料経路 Jd とし、貯蔵槽から箱への正味出入りを EF、EW とする。
ΔB = −Jp − Jd、ΔF = EF − Jd、ΔW = EW + Jd は、すべての履歴に対する整数の恒等式。
従って供給の化学仕事は W = μ Jd + log(z_F) ΔF + log(z_W) ΔW、ここで μ = log(z_F/z_W)。
一つ目は正味変換の項、残りは在庫の項である。μ<0 の計算で仕事を受け取る向きは W→F。
累積する環境エントロピーの記録は、局所速度比の対数の和であり W − ΔH と一致する。
在庫と分子数は有限なので、閉じた箱では |Jd| が常に有限で外部の W はゼロ。
受動経路を止めた開いた箱でも Jd = −ΔB が有界で、観測時間を無限にすると時間平均 W/T はゼロに収束する。
受動経路を含む開放箱では、B＋F→I＋W、I→B、W の排出、F の流入で一周できる。
この許容経路と逆経路の速度比の積は exp(μ)。駆動と受動の二経路が循環できる理由である。

受動経路を切ったときのグランドポテンシャルは
Φ = H + μ N_B − log(z_F) N_F − log(z_W) N_W。
局所反応では補助項の変化が相殺されるため、平衡重み exp(−Φ) と詳細釣り合いする。
材料の位置・状態を固定して溶媒サイトの F/W/空きについて和を取ると
(1+z_F+z_W)^(V−M) は全配置で共通。従って材料の平衡分布は df を df+μ にした分布になる。
B の総数を固定した対照では、この配置のエネルギー重みは exp(−ε N_BB) に比例する。
比較しているのは有限時間の履歴であり、計算時間内の平衡化は別途検証が必要である。

測定の定義と限界

濃集の主指標は、各サイトの材料占有率を周期的に4×4×4区画で平均した場の空間分散。
2×2×2 の分散と、幅4の場のしきい値0.3、0.5、0.7による成分を併記した。
幅4の分散を x だけに依存する成分と、各 x 面内の変動に厳密に分解した。
これにより供給面に沿う濃淡と面内の濃淡を別々に測れる。
壁を横切る接触対は周期境界で数える。成分内部でたどった経路を無限の繰り返し箱へ
持ち上げ、同じボクセルに異なる箱番号で戻れるときに巡回経路があるとする。
各軸の真偽は巡回の射影を表し、独立な巡回経路の本数や閉曲面の存在とは異なる量である。

燃料の接触については、B の近傍 F と I の近傍 W を直接数え、局所の n_B ごとの速度係数で重み付けした。
材料の各位置と n_B、空き得る近傍サイト数を固定したまま、全箱で混合した期待値と
同じ x 面だけで混合した期待値を比較対象とする。実際に配置を並べ替える操作は行わない。
この値は保存フレームから計算した反応の起こりやすさ。実際に発生した反応の回数は別のイベント台帳で検証した。

集団ごとの報告はシードごとの差の符号を保持し、その範囲を示す。3または4、6シードの記述的な比較である。
同一履歴のフレームと同一時刻までの前半は独立サンプルに数えない。
遅い時間帯は T300 で210〜300、T600で420〜600、T3000で2100〜3000。
区間平均はマッチした時計で台形積分し、端点がフレーム間にある場合だけ線形補間した。
有限体積の分子格子モデルであり、Nの変更で変わるのは物理体積である。連続体のメッシュ収束とは異なる。
分子は仮想的な接触エネルギーと遷移状態、等サイズの排除体積、暗黙の等温溶媒を仮定する。
分子種に対応付けた材料校正、流体力学、選択透過や膜の機械測定は今後の独立した検証が必要である。

第8監査と再現性

各履歴は一様に無作為化した配置から t=0 で始まる。材料の形、目標値、局在の場所は初期状態に置いていない。
材料2状態、燃料2状態、乱数シード、受動／駆動経路、供給幾何は宣言済みの入力である。
組成固定対照の割合も初期入力として扱う。面供給は外部環境の指定である。
軌道は形の測定から独立しており、しきい値、反応のカウント、図は状態を更新しない。
候補に応じた停止、クリップ、質量補修は行わない。失敗や弱い事例も秤量表から取り除かない。
保存した各 ZIP にレシピ、実行時の入力ハッシュ、CSV、時刻ごとの4種の状態配列を収録した。
既存結果と条件が完全一致する15枠は同じアーカイブへ参照を張り、追加の独立試行に数えない。
照合では元ファイルの SHA-256 に加え、位置を初期位置と巻き戻さない変位から再構成し、サイトと一致することを検査した。
時刻・反応の整数収支・結合数・貯蔵槽仕事・環境エントロピーも別の読取器で検査した。
状態更新器、既存のキャンペーン、正式 Room、科学的判定ゲート、bot の設定は no-touch とした。
実行環境は Python 3.10.11、NumPy 2.2.6、SciPy 1.15.3、Apple clang 17.0.0、x86_64。
同条件・同環境の再実行で既存の決定性検査が通った。異なる標準ライブラリやコンパイラでのバイト一致は仮定しない。

文献と比較の根拠

Cho と Jacobs の分子格子の研究は、界面のゆらぎと非平衡の流れが結合し得ることを示した。
本研究の試行は、明示的な F/W 輸送と無構造の3D初期状態についての別の条件である。
https://arxiv.org/html/2505.16824v1

連続時間の化学イベントの選択と待ち時間の基礎は Gillespie の確率的シミュレーション法を参照。
https://doi.org/10.1021/j100540a008

周期系での巡回経路と、切った箱での端から端までの連結を区別する考え方は Newman と Ziff にもある。
https://doi.org/10.1103/PhysRevE.64.016706

元の再集計で浮動小数点の末尾に最大2.22e−16の差を検出。台形和を固定順序に変更すると、2回の再集計で全6ファイルがバイト単位で一致した。記録は DETERMINISM.json。

次に比較すべき条件

まず一様供給で、材料状態が変わる可逆対照と反応ありの対照を使い、N48以上と長い観測時間で追試する。
組成、単位体積当たり供給能力、状態の入れ替わる総率を揃えた組を固定し、代表長さと体積ごとの時間変化を記録する。
長時間でも差が残る場合と、単に近づく速度が違う場合を分けるためである。
別案として、同じ予算で実在する可逆材料の結合・移動・透過を独立に較正する。
e060の次の数値診断では、固定時間での場の収束を先に確認し、旧695条件を段階的に再評価する。

再現方法

リポジトリのルートで次を実行する。g++ と requirements.txt の Python ライブラリを用意する。
図の出力は Matplotlib を使う。既存アーカイブから指標を再計算する場合は out をこのキャンペーンの evidence/ に指定し、解析の出力には新しい場所を使う。

  campaign=research/campaigns/20261119-transport-and-composition
  scratch=$(mktemp -d)
  out="$scratch/evidence"
  export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1

  python -m pytest -q research/campaigns/20261108-local-reactive-fuel/test_instruments.py research/campaigns/20261108-local-reactive-fuel/test_sparse.py
  python -m pytest -q research/campaigns/20261108-local-reactive-lattice-v02/test_instruments.py
  python -m pytest -q "$campaign/test_observe.py"

  python "$campaign/run.py" --phase all --out "$out" --scratch "$scratch/primary" --jobs 4
  python "$campaign/extend.py" --evidence "$out" simulate --scratch "$scratch/supplement" --jobs 4
  python "$campaign/equilibrium.py" --evidence "$out" simulate --scratch "$scratch/equilibrium" --jobs 4

  python "$campaign/analyse.py" --evidence "$out" --out "$scratch/measurements"
  python "$campaign/extend.py" --evidence "$out" analyse --primary-results "$scratch/measurements/results.json" --out "$scratch/supplement-measurements"
  python "$campaign/equilibrium.py" --evidence "$out" analyse --out "$scratch/equilibrium-measurements"
  python "$campaign/legacy.py" --out "$scratch/legacy"
  python "$campaign/replay_e060.py" --out "$scratch/e060"

  python "$campaign/render.py" --evidence "$out" --results "$scratch/measurements/results.json" --supplement-results "$scratch/supplement-measurements/results.json" --reversible-results "$scratch/equilibrium-measurements/results.json" --out "$scratch/figures"

実行済みの値は measurements/、supplement-measurements/、equilibrium-measurements/ の JSON にある。
各ディレクトリの observations.json.gz にはフレームごとの測定を収録する。原状態配列は evidence/ の ZIP。
フレームの配列は uint8 のセル（Fortran順）、int32位置、uint8状態、int64変位である。
時刻を進めるカーネルと、表示・後処理のコードは別プロセスで動く。
校正の記録は INSTRUMENT_VALIDATION.json と validation/instrument-fixtures.tar.gz に収録した。
計算器13件、追加測定器5件、既存の3D幾何・流束58件、研究索引2件の関連検査を確認した。
図の field-evolution.png は最初の登録シード421、z=16を固定して、全4条件の時刻0、300、600を同じ色範囲で表示。
原計算の濃度を幅4で周期平均した表示で、見栄えに応じた位置合わせや誇張は行っていない。
