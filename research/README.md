# research/ — 人間と AI の研究の受け渡し

- `inbox/`：AI（や人）からの実験提案。`/propose` で作る。**ここにある間は実行しない。**
- `decisions/`：うえきさんが採否を決めた提案（ファイルを移し、front-matter の `status` を `accepted` / `rejected` にして理由を追記する）。

研究の索引は [index.json](index.json)、そこから生成する現在地は [研究の羅針盤](../RESEARCH_COMPASS.md)。人と自動実験者が計画・生データ・追試を受け渡す際は [研究の前提と記入例](../docs/STUDY_DESIGN.md) を参照する。実行済みの研究は `campaigns/` にある。
