# physics-integrity：「それは育ったのか、置いたのか？」

根拠は `AGENTS.md`、`docs/ANTI_DRIFT.md`、`docs/PHYSICS_INTEGRITY.md`（第8監査）、`LAW.md`（7監査）。
次の各項目に、ファイルと行を示して答える。1 つでも No なら、主張を弱めるか frontier に落とす。

## 始原条件
- [ ] 初期条件は一様＋ノイズか、対称なもの、または種だけか。完成形（渦・リング・膜・スポット・器官）を置いていないか。
- [ ] 置いたものは `put_in` として全部列挙したか（例：Swift-Hohenberg の局在の種）。
- [ ] 毎回 t=0 から回しているか。途中から機能や項を足していないか。

## 法則
- [ ] 局所的か（近傍だけ）。中央制御・大域 oracle・生死の条件分岐・外部からの分裂命令が無いか。
- [ ] 項を足したなら、それは「別の白」として扱ったか（`mutation_type: law_variant`）。
- [ ] 保存量を壊す補正や、特定の形へ収束させる強制項が無いか。

## 測定と評価
- [ ] 測定器は結論を知らないか。評価ゲートが結論と同型の因果を含んでいないか（第8監査）。
- [ ] 成功条件を、結果を見た後で変えていないか。失敗 run も残しているか。
- [ ] 2D の結果を 3D の主張に使っていないか。3D の主張は本物の 3D か（`three_d_authenticity`）。
- [ ] 同じ seed で決定的に再現するか。

## 言葉
- [ ] 「生命」「脳」「身体」「個体」などの強い語を、定義を満たさずに使っていないか。「◯◯候補」で足りるか。
- [ ] 同じ絵は同じものではない（トーラスの絵でも、生命や意識とは言わない）。
- [ ] claim tier（measured / observed / interpretive / analogy / frontier）を付けたか。
