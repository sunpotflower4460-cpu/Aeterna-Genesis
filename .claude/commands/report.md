直前の作業について、AGENTS.md の「報告フォーマット」に従って次の3点を出してください。

1. **📸 スクリーンショット**：`tools/snapshot.py` で作った PNG を送る（無ければ作る）。可視化は物理データと分けて扱う。
2. **😊 やさしい説明**（チャット本文・専門語を避ける）
   - 今回 0 からどこまで進んだか
   - 順番に何が起きて、いま何をしているか
   - 次にやりたいこと（選択肢と推奨）
3. **📄 監査用報告**（`docs/reports/YYYY-MM-DD-<slug>.md` に保存してダウンロードできるようにする）
   - 主張と claim tier
   - 測定（数値・seed・格子・ステップ数）
   - 限界・弱点
   - 再現手順（コマンドをそのまま）
   - 規律チェック：no_touch、tier、第8監査、決定性、2D/3D

2 と 3 は**必ず別々に**書く。測ったことだけを、限界つきで伝える。
