# MULTIWORLD_GENESIS — 複数の「0」と法則を並列に研究する

## 目的

Genesis を「g001 を深くする装置」から、**異なる 0・場・法則・次元を持つ小さな宇宙を並列に観察する研究所**へ拡張する。

> 最も少ない前提から、どの種類の秩序・関係・持続・個体性・分裂・継承・幾何が自然に現れるかを測る。

## 2. Zero registry

「0」は数値 0 と同義ではない。対象法則に対して、構造・位置・向き・個体・トポロジーをなるべく入れていない状態を分類する。

- **Z-A minimal-white**: 一様/最大対称状態 + 無相関微小ノイズ。長さスケールを置かない。
- **Z-B correlated-random**: 物体やトポロジーは置かないが、相関長/スペクトルを置く。
- **Z-C ensemble-prepared**: 明示した統計アンサンブルから生成。
- **Z-D process-prepared**: 上流の物理過程/親 World から生成。C2/C3 方向。
- **Z-R relational**: 固定 metric/coordinate lattice を原始入力としない C4 frontier。

Z-B が価値の低い start という意味ではない。ただし「長さスケールすらない起源」の証拠は Z-A より弱いので区別する。
