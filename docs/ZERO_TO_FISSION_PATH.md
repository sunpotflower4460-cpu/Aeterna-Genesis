# ZERO_TO_FISSION_PATH — 0から自然に「分かれる」まで

Genesis の長期目標の一つとして、**何かを配置・設計して分裂させるのではなく、同じ run が時刻0の未分化状態から自然に段階を上がり、最終的に「1つの関係網が2つ以上へ分かれる」までを連続観測する**。

これは [`EMERGENCE_LEVELS.md`](EMERGENCE_LEVELS.md) の公式 Level を置き換えない。公式 Level は科学的到達深度、こちらは **Level 7（成長・分裂・継承）へ近づくための観察経路／研究ナビゲーション**である。

## 観察経路 0 → 7

0. **ほぼ何もない揺らぎ** — 個体・渦・三角形・分裂位置を置かない。
1. **違いが生まれる** — 未分化な場から差・模様・秩序が自然に立つ。
2. **局所構造が生まれる** — 渦などの局在構造が自然に現れる。
3. **構造どうしが関係を作る** — 複数の局所構造が持続する局所関係を作る。
4. **一時的な安定配置** — 現在は「持続する3渦三角形」を一つの候補として測る。ただし三角形は必須経路とは決めない。
5. **バランスが崩れる** — 同じ局所集団がまだ1群のまま、辺比・面積比・三角形資格などの均衡を失う。
6. **1つのまとまりとして不安定化** — バランスを失った後も一時的には1群を保つが、その状態が持続する。
7. **2つ以上へ分かれる** — 上の順序の後、局所関係網が2群以上へ持続的に分離する。

段階7は現時点では **network-fission candidate（関係網の分裂候補）** であり、生物学的な細胞分裂とは呼ばない。将来、自然に生まれた境界・内外差・追跡可能な個体性について「1つの連結した全体 → くびれ → 2つの持続する全体」を測定できたとき、公式 Level 7 の分裂主張へ近づける。

## 絶対にしないこと

- 三角形を初期条件に置かない。
- 渦の位置・符号・巻き数を目標に合わせて置かない。
- 分裂位置・分裂時刻を与えない。
- 「段階4まで進んだrun」に後から分裂機能を追加しない。
- 途中の別runをつなぎ合わせて「0→7まで進んだ」と呼ばない。
- 三角形が出なかった経路を失敗扱いしない。三角形を経由しない自然な分裂経路も探索対象に残す。

## 競合する2つの三角形仮説

### H1: 三角形＝分裂装置仮説

自然にできた持続三角形そのものが、非三角形の比較群より後の分離を起こしやすくする可能性。

**反証**：繰り返し比較しても三角形の分離率が比較群を上回らない。

### H2: 三角形＝一時安定、バランス崩壊＝前兆仮説

三角形は一時的な釣り合いであり、三角形があること自体ではなく、**まだ1つの局所集団のままその釣り合いを失うこと**が後の分離を予告する可能性。

**反証**：バランス崩壊を観測した三角形と、崩壊しなかった三角形で、その後の分離率に再現可能な差がない。

両仮説は同時に保持し、片方を正解として探索空間へ埋め込まない。

## 自動研究での扱い

通常の広域探索・Native 3D・反証・ランダム探索を維持したまま、段階4以上まで自然に進んだ条件を **Frontier Lead** として別枠で少量追試する。

追試は次の3方向：

- **exact**：開始条件は同じ、乱数だけ新しくする。
- **local**：開始側の許可されたパラメータを少しだけ変える。
- **contrast**：意図的に離した条件でも同じ経路が出るか試す。

`exact/local` が強くても `contrast` も同程度に強ければ、元の一点が特別なのではなく「もっと広い領域の現象」と解釈する。Frontier Lead の状態は研究案内であり、公式 Room・Level・成功閾値を変更しない。

## 「0から」の厳しい扱い

0→7の**厳格な連続到達**では、離散的な物体を初期配置する IC family を除外する。現在は `white`, `white_lowk`, `white_highk`, `spectral_powerlaw`, `bandpass` のような「離散物体を置かないランダム場」だけを strict-zero eligible とする。

`single_seed`, `sparse_seeds`, `ring`, `gradient` 等は探索・機構理解には残すが、その run を「厳しい0から分裂まで」の証拠には数えない。

## 3Dについて

Native 3D の独立探索は従来どおり2D失敗で止めない。現時点の0→分裂の幾何追跡は2D断面の3渦関係に限定されるため、**3Dでの分裂経路を未測定のまま2D結果から推定しない**。将来は渦線・局所全体性・3Dの分岐を直接追跡する専用診断を追加する。
