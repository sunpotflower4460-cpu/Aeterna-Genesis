# Autonomous Frontier Expansion

Aeterna の研究目的は、決められた段階表を埋めることではない。

最上位の目的地は、現在の最小仮説 R0 から結果形状を与えずに、宇宙・脳・種からの成長に必要な機能が自発的に成立するところまで進むことである。

## 固定するもの

- 目的地
- Pure Genesis の誠実性
- 新しい物理前提には Why Chain が必要という規則
- target morphology / vortex / pair / triangle / split / brain / plant morphology を Pure Genesis の答えとして seed しないこと
- scaffolded experiment を Pure Genesis の達成証拠に混ぜないこと
- negative evidence を捨てないこと

## 固定しないもの

- 仮説
- 参照ルート
- 実験方法
- 観測量
- 次に作る診断器
- どの現象を深掘りするか

F0-F7 は引き続き一つの人間記述の参照ルートであり、自然の正式な一本道ではない。

## 自動拡張の考え方

現在の証拠を見て、その時点で最も情報が増える次の行動を選ぶ。

- 未知遷移が何度も現れる場合は、再現回数を増やすだけでなく、一つずつ開始側の条件を変えて何に敏感かを見る。
- 深い関係不安定化候補が出た場合は、完成形や分離位置を与えず、開始側の条件を一つずつ変えて深さが変わる理由を探る。
- R0 由来の候補則が残った場合は、演算子を一つずつ外し、どれが必要に見えるかを Root Integrity 後の値で比較する。
- 目的地に必要なのに現在測れない能力がある場合は、新しい測定器・介入器の要求を自動生成する。

これらは固定順序ではない。証拠がなければそのレーンは走らず、予算は現在意味のある別の問いへ移る。

## 目的地の能力地図

宇宙・脳・植物の完成形を定義する代わりに、途中で必要になる機能を観測対象として管理する。

- 内側から新しい区別が増える
- 区別どうしが持続関係を作る
- 名前を先に与えない反復変化
- ラベルを消しても残る閉じた関係
- 多段階・多尺度の階層
- 過去の違いが後の変化へ残る
- 持続する個体性
- 自己維持と修復
- 収支を伴う成長
- 役割分化
- 未経験変化への適応
- 関係から後付けで距離・幾何を定義できる可能性
- 個体分裂・収支・継承

「脳らしい」「植物らしい」「宇宙らしい」という強い主張は、一つの指標だけでは認めない。

## Scaffolded parallel lane

与えた形・環境を使う補助実験は許可する。これは機構を理解したり、必要な観測器を設計するための実験台である。

ただし、その結果は Pure Genesis のゼロからの創発証拠として数えない。補助実験で得た仕組みを Pure Genesis 側へ持ち帰る場合も、答えを seed せず独立に再発見・再検証する必要がある。

## 人向け報告

裏側では技術的な実験結果を保存するが、first-read report は以下を優先する。

1. 目的地
2. 現在地
3. 今回何が前進したか
4. 最大の未達点
5. 次に何を確かめるか

内部 ID、細かな試行回数、探索パラメータは証拠として JSON に残し、人向けの最初の説明では要求しない。
