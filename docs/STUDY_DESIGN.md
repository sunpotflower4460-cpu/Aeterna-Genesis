# 「生命の宿りうる器」を調べるための研究の前提

目指すのは、物理的な材料と環境が局所で関わり続ける一つの履歴から、境界、維持、分岐、信号をやり取りする組織がどこまで育ちうるかを知ること。脳の形、配線、機能名は出発条件に含めず、現れた性質に一つずつ測定の根拠を付ける。「生命の宿りうる器」はこの動機を表す言葉として使う。[現在のはしご](LADDER.md)

## 何を「証明した」と書けるか

| 発表したいこと | 必要な根拠と書き方 |
|---|---|
| ある量が必ずこの関係を満たす | 前提、定義、導出または形式的検証を示す。「この法則の下で、何が、どの範囲で成り立つかを証明した」と書ける。丸め誤差や有限回の一致は別に測る。 |
| この系で出来事が起きた | t=0 を含む生データから、時刻、条件、観測量を示す。「この条件の全 n 本中 k 本に観測した」と書く。再生の一致は一つの履歴の再現性を支える。 |
| この機構が寄与した | 競合する説明を列挙し、問いに対応する対照と未使用条件で効果の大きさと不確かさを示す。複数の係数が同時に変わる比較では、その組み合わせに帰属する。必要性・十分性は調べた条件の範囲に限る。 |
| 現実の物質にも当てはまる | 物質名、単位、物性値の出典と誤差、近似の尺度を示す。校正に使った値、適合には使わなかった既知資料、事前に封印した未見資料、自分たちの新しい物理実験を区別する。独立した測定と予測の残差を示し、有効範囲を書く。 |

主張ごとに従来の role と claim tier を併記する。保存則が閉じることは実装の検証に役立つ。実物との対応には別の測定が要る。校正・検証の区別と事前登録の考え方の出典。[Oberkampf と Trucano](https://www.sandia.gov/research/publications/details/verification-and-validation-in-computational-fluid-dynamics-2002-03-01/)・[Nosek ほか](https://doi.org/10.1073/pnas.1708274114)

## 始める前と読み終えた後に残すもの

| 時点 | 記録 |
|---|---|
| 世界を選ぶ時 | 法則の各項、係数と単位、実測・文献・導出・仮定のどれに由来するか。省いた自由度と成り立つ尺度を書く。A〜D の法則監査には物質や過程ごとの根拠を付ける。仮の材料には仮の名を使う。 |
| t=0 と環境を決める時 | 初期分布、相関、用意した構造、境界、熱・物質・仕事の供給源を書く。物理的相互作用の局所性、数値計算の大域操作、観測の大域集計を個別に記す。測定値から世界へのフィードバックも入力に数える。 |
| 探索する時 | 試した範囲、誰が何を見て次の条件を選んだか、止めた理由を残す。異常、未成立、発散、未実行も区別する。見つけた後に考えた指標には発見時点を付ける。新しい着眼を記すのに確認試験の完了を待つ必要はない。 |
| 確かめる前 | 主張文、独立な試行の単位、対照、観測間隔、時刻窓、閾値・許容誤差の根拠、対象となる試行、打ち切り、予算、代表画像の選び方を固定する。確認用の初期条件や資料の既読範囲も記す。分析者が条件を伏せて測れる場合は対応表を最後に開く。 |
| 結果を読む時 | 全試行の分母、各試行の値、効果量と不確かさ、欠測・失敗・曖昧な事例を報告する。時系列のコマ、境界の複数閾値、一つの履歴の再生を独立な試行に数えない。多数の尺度を調べた選択は開示し、推測統計を用いる場合は多重比較や時間相関を扱う。 |
| 再検証する時 | 生データ、コード版、乱数生成器、環境、再生手順を結ぶ。測定器の陽性・陰性対照、既知極限、独立した計算法、箱サイズ・空間刻み・時間刻み・観測間隔の感度から、そのモデルに意味のあるものを選ぶ。未知の依存性は未検証と記す。 |

時刻を決めて環境を切り替える試験や、状態を複製して行う対照も使える。介入を受けた枝と、同じ準備を通った継続・擬似介入の枝を記録し、外から与えた切替を自律履歴の出来事として数えることを防ぐ。結果を見て解析条件を変えた時は旧版と理由を残し、新条件の確認には未使用の試行を割り当てる。

## もし一つが二つに見えたら

1. まず「密度の連結領域が一つから二つになった」と記録する。観測閾値をまたいだ細い橋、周期境界を越えた一つの領域、視野への出入り、並んで発生した二領域でも同じ計数になりうる。既知の一体・分離・再結合の入力を測定器にだけ与えて誤検出を調べる。
2. 同じ3D履歴で親の前史、二つへの物質配分、各々の境界・持続時間、再融合、追跡不能例を見る。密度の切り方、測定間隔、空間尺度を変えて系譜が保つか調べる。親ラベルを更新式で娘にコピーすると、そのラベルの継承は与えた性質になる。
3. 形の分岐、物理的な区画の分裂、分裂後の個々の維持、内部状態の継承は個別に主張する。細胞分裂を論じるには、何を細胞と呼んだか、親と娘がその定義を満たすか、物理的な材料と交換の対応を示す。継承を扱う際は共通の外部環境や無作為な材料分配でも説明できる分を測る。適切な持続時間・効果量は系の物理時間から確認前に決める。

脳についても同じ手順を使う。自発的な信号伝播、結合の形成、履歴に依存する応答を別々に測る。応答を外部の学習器が読み取った場合、その学習器が担った機能を明記する。「脳」には組織と機能の双方について実物と比べられる定義が要る。「意識が宿った」という解釈はこれらの観測からは判定できない。

## 探索の選択肢を増やす

- **物理モデルを広げる。** 新しい物質、流体との結合、熱・電荷の輸送、空間的に偏った環境などを、現実の機構や物性から動機づけた別の始原条件として試せる。複数因子を交差させれば相互作用も調べられる。新しい3Dモデルは直接 t=0 から始められる。近似モデルも測定器の開発や近似の破れる領域の探索に使える。
- **次の一手を、説明の違いから選ぶ。** 手動でも自動でも、残る説明を二つ書き、どの条件で違う測定値になるかを考える。未知の範囲を広く測る、既出の発見を別条件で確かめる、物性値を調べ直す、のどれにも予算を使える。結果が同じならその範囲を閉じ、再開に必要な新資料・尺度・対照を記す。
- **別の世界で得た性質には出典を残す。** 異なる模型で測った「境界」と「信号応答」を一個体の履歴に足し合わせることはできない。同じ未介入の履歴で両者と依存関係を測れた時に、統合した主張を検討する。別の世界から材料を受け渡した比較はその準備過程を明記する。

## 手動と自動で共用する記録

自由探索は通常のラボやノートから始められる。事前に条件を固定して確かめる時は、従来の登録様式も使える。次の短い検査コマンドは特定の物理エンジンを要求しない。[記入済みの計画](../research/campaigns/20261120-water-diffusion-reference/PLAN.json)・[対応する結果台帳](../research/campaigns/20261120-water-diffusion-reference/evidence/record.json)

```sh
python -m tools.study_record path/to/PLAN.json
python -m tools.study_record path/to/PLAN.json path/to/evidence/record.json
```

計画には問い、既読範囲、独立単位、入力、測定法、対照、打ち切り、コード等の追跡対象、試行条件を記す。計算結果を左右するソース・設定・依存バージョンを列挙する。固定した計画と入力を Git に記録し、確認用のデータを開く前に外部から参照できる版を残す。結果台帳はその完全なコミットIDを指し、計画の全条件に全試行の記録を結ぶ。再試行は同じ条件の配列に追記する。完了には生データなどのファイルと SHA-256、失敗・中断・未実行には理由を記す。ダウンロードした大きな証拠は台帳を基準とする同じ相対パスに配置できる。

検査が確かめるのは指定コミットとの内容一致、予定条件との照合、記録されたファイルの内容である。結果の選択や未申告の試行、事前に何を知っていたか、物理的な妥当性は、資料の履歴と独立した読み直しを含めて評価する。水槽の点数もこの検査の終了コードも、はしごの段を上げる条件に使わない。
