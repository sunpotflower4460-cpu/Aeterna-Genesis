## 2. 測定と再現手順

```bash
pip install -r requirements.txt
python -m pytest -q tests/test_lab_*.py -m "not slow"     # 50 件前後・約 40 秒
python -m pytest -q -m slow tests/test_lab_registry.py      # つまみの角・長い版（約 100 秒）
(cd app && npm install && npm run build)
python -m tools.lab.server                                  # http://127.0.0.1:8765/#lab
python -m tools.lab.observe --white sh --frames 40 --out /tmp/pk    # サーバーなしで観測パケット
python -m tools.lab.replay research/sessions/<id>           # 書き出した記録を t=0 から
```

実測（この container・1 コア）：3D 48³ の TDGL は 1 ステップ 7.3 ms、GS 96² は 0.2 ms、三成分 96² は 2.0 ms。フレームごとの測定は 3D で約 15 ms。

## 3. 限界・弱点（正直に）

- **数値の安定のため、つまみの範囲を狭めた**（物理の限界ではない）。
  - 見つかった経緯：Codex の指摘と、CI（別の環境の FFT）で発散したこと。
  - 狭めた範囲：TDGL は Du≤1.4、GS は Du≤0.2、SH は r≤0・b≤2.1、CGL は |b|,|c|≤2。
  - それでも発散したら、ワーカーが止めて「計算の限界」と表示する。
- **事件簿**
  - 規則は機械的だが、閾値の選び方に依存する（jump の k=6 と幅 5%、settled の 20% と 1%、period の acf>0.5、追跡の半径）。
  - 追跡は表示用のフレームで行っている（2D は間引きなし・uint8 の量子化 1/255）。1 マス前後の移動は、形の変化や量子化でも起こる（事件簿にも明記）。
  - GS の成長初期は `jump` が何度も出る（測定としては正しいが、うるさい）。
- **3D**
  - GPE の輪は xy 面にあり、`winding_defect_count` では見えない。代わりに芯の体積（|ψ|²<0.3）を報告している。
  - 輪の追跡（継ぎ目の残骸と区別するもの）は未実装。計画にはあったが、今回はやっていない。
- **AI の会議**
  - 実際の API キーでは、まだ一度も呼んでいない。
  - Gemini（google-genai）の経路は、偽のサーバーでも通していない。
  - 見る係の出力は「見た目（未測定）」のラベルを必ず付けるが、中身の正しさは保証しない。
- **描画**：確認したのは headless Chromium（SwiftShader）だけ。実機の GPU とスマホの実機では、まだ見ていない。
- **パラレル宇宙**：同時に動かせるのは CPU コア数まで。3D は 48³ まで。
- **記録**：replay で作り直せるのは最後の状態（sha）まで。途中のキーフレームは、replay のときに作り直したもの（`--packet`）。

## 4. 規律チェック

- **no_touch**
  - `genesis/models/*` と `core/*` は変更していない。
  - 測定器（`genesis/diagnostics/*`）も変更していない（呼んでいるだけ）。
- **置いたもの**
  - つまみの変更・摂動・分岐はすべて、時刻付きの出来事としてレシピ・画面・事件簿・記録に出る。
  - 始め方のつまみは t=0 でしか選べない。
- **主張**
  - ラボ・事件簿・会議・書き出しには「見たことの記録で、主張ではない」と明記した。
  - 主張にするには replay と `/audit` を通す、という順序を、`docs/LAB.md`・`research/sessions/README.md`・`/guide` に書いた。
- **AI**
  - 提案は人が押すまで実行されない（テスト済み）。
  - 見る係の発言には必ず「未測定」のラベルが付く。
  - キーは環境変数だけで扱い、応答にも記録にも出さない（テスト済み）。
- **自動化**：bot の trigger は戻していない。ラボはうえきさんが起動したときだけ動き、main には書かない。
