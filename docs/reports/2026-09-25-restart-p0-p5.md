## 3. 限界・弱点（正直に）

- **X 監査**
  - 対象は 2D quick TDGL だけ。ラベルは直前と直後のスナップショット 2 枚の大域量から付けている。
  - H1（対消滅）は位置を追跡していないので、「偶数だけ減り、巻き数が保存される」という必要条件での判定。
  - NOT_REPRODUCED の 91 件は「20 seed で出なかった」という意味で、「存在しない」ではない。57 件は再現用の条件が無く、Stage A の分類だけ。
  - **初版（4a8d670）には偏りがあった**：後半の出来事を根拠なしに緩和とし、過去の観測数を外挿して 82% と書いていた。Codex の指摘で直した。
  - 直した後も、平坦値の判定（最後の 3 枚が 5% 以内）と緩和の判定（gradient_rms と amp_std が増えない）は、閾値の選び方に依存する。
- **決定性**：同じ環境での一致を見ただけ。別の BLAS や FFT でのビット一致は未確認（weekly-integrity でも見ていない）。
- **分類**：代表は「最小 seed」、外れ値は「|z|>3」という機械的な規則で選んでいる。人の目では見ていない。
- **validate_schemas**：result_room のエラーが 2,695 件残っている。gl-haiku-1000 の job が指す Room が、もともと commit されていないため（既存の問題）。
- **P0**：run の cancel は 403 で拒否された。2026-09-13 から queued のまま止まっている run が 2 件ある（34748579138、34748579151）。凍結タグ `evidence-freeze-2026-09` は未作成（うえきさん側の作業）。48 時間の静穏確認は 2026-09-27 19:14 UTC に行う。
- **水槽**
  - 可視化は uint8 に量子化し、run 全体の vmin/vmax で規格化している。そのため、後半の小さなコントラストは見えにくい。これが原因で mass-conserved-ball は外した（C8 とは別件）。
  - GPE の輪は「置いた」もので、位相の継ぎ目の影は作り物（カードに明記）。
  - 描画確認は headless Chromium（SwiftShader）だけ。実機の GPU ではまだ見ていない。
- **Codex のレビュー**：#144〜#146 では投稿されていない（大きな差分のためか）。#140 と #143 の指摘には全件対応した。
