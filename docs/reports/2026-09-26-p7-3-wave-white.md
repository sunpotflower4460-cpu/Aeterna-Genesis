## 0. なぜこの白か（P7「光から考え直す白」）

拡散の白（反応拡散・GL）では、影響が一瞬で（弱く）全体に届き、時間の矢（散逸）が法則に最初から入っている。
波の白は次の 3 点が違う。
1. **有限の速さ**（光円錐）で伝わる。
2. **可逆**（γ=0 なら時間を戻せる）。
3. **局所 × 並列 × 中央なし**（最近接のステンシル・leapfrog、FFT なし）。AGENTS.md の「現実に忠実な起き方」。

まず「光のように振る舞う」ことをテストで確かめてから、何が置かずに育つかを測った。

## 2. 測定と再現手順

```bash
pip install -r requirements.txt
python -m pytest -q tests/test_wave_klein_gordon.py                  # 9 件・約 1 秒
python tools/wave_first_look.py --out /tmp/wave                      # 12 run（約 10 分・1 コア）→ summary.json と PNG
python tools/wave_first_look.py --out /tmp/wave --quick              # 1 seed・t=400
python -m tools.lab.server   # ラボで wave-phi4 / wave-sine-gordon / wave-phi4-3d を選んで t=0 から
```

条件：
- 128²、dt=0.2、dx=1、λ=1、noise=0.01、bias=0。
- 吸い込みは γ=0.3・幅 8。
- 局在塊の判定の手順：
  1. t=2000 から 100 時間、エネルギー密度を平均し、0.05×山の高さを超える連結領域を探す。
  2. その中心の φ を 500 時間記録し、FFT で主な周波数を求める。
  3. 中心のまわり 21×21 の窓で、エネルギーの始めと終わりを比べる。

速さの実測（この container・1 コア）：
- 2D 128² は 1 コマ（10 step）が約 4 ms。
- 3D 48³ は 1 コマ（5 step）が約 40 ms（測定を含む）。

## 3. 限界・弱点（正直に）

- **オシロン候補は tier candidate**。
  - 判定は「中心の 1 点で、ギャップより低い周波数」と「窓内のエネルギー」だけ。塊の追跡（動いたときに追いかける）はしていない。
  - 窓からの減少は、移動と減衰を区別できていない。
  - 「ギャップより低い」だけの基準では、静止した構造（ω≈0：SG seed 1 の壁の交わり）も通ってしまう。W7 では振動しているもの（ω > 0.5×ギャップ）だけを数えた。
- **局在を見るには、端の吸い込み（時間の矢）を置く必要があった**。
  - 閉じた箱にもオシロンがあるかもしれないが、熱い放射の中で区別する測定器をまだ持っていない。
  - これは仮説 H2（流れ・出口が要る）とつながるが、H2 の検証ではない。
- **φ⁴ の対称性の破れのあとにオシロンができることは、既知の現象**（文献で知られている）。新しい発見ではなく、この白が「光のように振る舞い」、置かずにそこまで行くことを確かめた、という位置づけ。
- **その他**：
  - 2D だけで測った。3D（wave-phi4-3d）はラボに入れたが、測定はまだしていない。3D が本線（AGENTS.md）なので、次の課題。
  - seed は 3 つだけで、統計は弱い。
  - dt=0.2 を固定した（CFL 条件 dt < 1/√ndim）。つまみにはしていない。
  - `lumps`（瞬間値、0.5×山の高さ）は、熱い箱では揺らぎも数える。個数ではなく、壁と塊の区別の手がかりとして使う。

## 4. 規律チェック

- **no_touch**
  - 既存の `genesis/models/*`・`core/*`・`genesis/diagnostics/*` は変更していない。モデルは新しく追加した。
  - ラボの白は、そのモデルを呼ぶ薄い包み。
- **置いたもの**
  - 法則（ポテンシャルの形＝谷の数と位置）。
  - t=0 の山の上の一様な場＋ノイズ（振幅 0.01）。
  - 端の吸い込み（γ>0 のとき）。
  - いずれもラボの `put_in` と報告に書いた。壁・塊の位置・数・形は置いていない。
- **第 8 監査**：評価（壁の密度・局在塊・周波数）は、結論と同じ形の因果を方程式や初期条件に入れていない。ギャップの値は、真空での線形の質量から計算した。
- **決定性**：同じ seed なら、ビット単位で一致する（`test_deterministic`）。ラボの白は Universe のレシピで replay できる（既存の仕組み）。
- **強い言葉**：「オシロン候補」「局在塊」と書き、「粒子」「個体」「生命」とは言っていない。

限界：
- **3D の負の結果の範囲**：試したのは 64³ だけで、吸い込む層（幅 8）が箱に対して厚い。t=0 のノイズも一種類。3D でオシロンが残らないと一般には言えない（大きな箱・弱い吸い込み・長い時間は未試行）。
- **閉じた箱**：熱い放射で、しきい値（0.05×山の高さ）を超える領域が箱全体につながった。そのため塊の追跡ができなかった（測定器の限界）。
- **追跡の窓**：10 時間平均のエネルギーで追跡した。塊の合体・分裂が多い（φ⁴ 2D で数百回）ので、同一性の判定は窓の長さとしきい値に依存する。
- **影響の分類の境目**：「局所でない」は、最近接ステンシルの 1 ステップ 1 セルの上限を超えたかで決めた。直線/√t の比のしきい値（1.5・2）は、この repo の白での実測から決めた。
  - `reach`（1e-12 を超える変化）は、格子の数値の尾として、光円錐の外（ステップあたり 1 セル以内）にも出る。物理として意味のある前線（最大の 0.1%）だけが c に従う（テストに明記）。
- **H5 への意味**：「まだ届いていない外」がはっきりあるのは波の白だけ。拡散の白は局所だが、前線がだんだん遅くなる。FFT を使う白は、最初から全体がわずかにつながる。塊の独立性との関係は、まだ測っていない。そのために H5 を「すぐ始められる」にした（研究員の道具 `influence`）。
