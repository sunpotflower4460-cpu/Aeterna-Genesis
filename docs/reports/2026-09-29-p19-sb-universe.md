## 1. 法則（分類 A：現実の場の方程式、古典統計の近似）と条件

宇宙は「仕様」（dict）で決まる。仕様から法則を組み立てる。

```
実数の場  φ_r：   H_r = ½π_r² + ½c_r² Σ_i(φ_r(x+î) − φ_r(x))²
複素の場  φ_a：   H_a = |π_a|² + c_a² Σ_i|e^{-iθ_i(x)}φ_a(x+î) − φ_a(x)|²      （U(1) の電荷 1）
光のような場：    (e²/2)ΣE² + (1/e²)Σ_{i<j}(1 − cos P_ij)                       （コンパクトなリンク、e=0 はなし）
ポテンシャル V：   不変量 s = ½Σφ_r² + Σ|φ_a|² の多項式（下の表）
```

- 時間の進め方：ハミルトン型の kick–drift–kick（leapfrog）。**最近接だけ**（FFT・大域の解法は使わない）。
  - temporal gauge で、ガウスの法則 div E = Σ 2Im(φ_a*π_a) が丸め誤差まで保たれる。
  - 刻み dt は仕様のいちばん速い波から自動で決める：cfl·2/√(4d·c²_max + |V''|_max)。
- 外の条件：
  - 閉じた箱（エネルギー保存）。
  - 放射の時代の膨張（共形時間、a = 1 + Hτ、χ = aφ で χ'' = c²∇²χ − a³V'(χ/a)。ゲージ場は共形なので変わらない）。
    - 格子で分解できるのは、谷の一番重い波の長さ 1/(m·a) が 1.5 マスになるまで（a_max ≈ 2.1）。H はそこに T=400 で届くように選び、そこで止めた。
- t=0：
  - 対称な点 φ=0 に、**量子の真空の揺らぎ**。どの波にも ħω/2（truncated Wigner。古典統計の近似）。
  - 熱い始まり T0 > 0 では、各波に n + ½ 個の量子（n = 1/(e^{ħω/T0} − 1)）。
  - 光のような場があるときは、全体の電荷を 0 にし（ガウスの法則のため）、E ＝ クーロン場＋光子自身の真空の揺らぎ。
  - FFT は t=0 の揺らぎを作るのと、測定だけに使う。

最初の差の形（プリセット）。係数は、谷の一番重い波の長さ 1/m が約 3 マス（格子で分解できる）になるように選んだ。

## 2. 名前を先に付けない数え方（`emergence_census.py`）と、その検証

どの仕様でも同じ数え方をする。

| 量 | 数え方 |
|---|---|
| 谷 | 各点の場の値を V の坂に沿って転がし（点ごと。測定だけ）、行き着いた先を鎖状にまとめる。連続の谷は、谷底を通ってつながるかを確かめて 1 つにまとめる。山の頂上・鞍点に止まった点は谷にしない。谷の「平らな向き」の数（ヘッセ行列）で、点か円かを見分ける。光があるときは、ゲージ不変な座標でまとめる。 |
| 谷の中／谷の間 | 谷から、その谷の縄張りの境（隣の谷との中点、または対称な点）までの半分より近ければ「谷の中」。それ以外は「谷の間」（頂上・壁・芯）。 |
| 領域 | 同じ谷の「中」の点がつながった塊（周期境界）。27 マス以上を「大きい領域」。 |
| 出会い方 | 境目の集合（谷の間の点＋別の谷と接する点）をつながりごとに分け、いくつの谷に触れるかで数える：1（ひとつの領域の中の穴・芯）、2（2 つの出会い。どの谷とどの谷か）、3+（3 つ以上が出会う所）。 |
| 位相の巻き | 複素の場ごとに、プラケットを回る位相の巻き（光があるときはゲージ不変な形）。 |
| 塊 | エネルギー密度が 平均＋3σ を超える、箱の半分より小さい塊。中の電荷・巻き・谷。2 時間ごとに光円錐の速さの範囲で追跡し（`lump_tracker`）、**100 時間以上追えたものを「長く生きた」**とする。 |
| 全く同じか | 同じ種類（谷）の 27 マス以上の領域・塊どうしで、大きさと慣性モーメント（形）の相対差が最も小さい組と、1e-9 以内で一致する組の数。 |
| 帯（ω–k） | ゲージ不変な局所の量（\|φ\|²、実数の場、磁場 sin P）の軸方向の波を、最後の 200 時間、0.5 ごとに記録し、時間の FFT で振動数の山を探す。 |

検証（`tests/test_emergence_census.py`、手で作った場）：
- 2 つの谷の板 → 領域 2、壁 2 本（どちらも 0-1）。
- 中庸の谷の中の揺らぎ → 谷 1 つ、谷の間 0（数え方の誤りを直したときの回帰テスト）。
- 3 つの扇 → 谷 3 つ、3 つが出会う所がある。
- 円の谷をまばらに取っても 1 つ（平らな向き 1）。
- 2 段階（円 × ±）→ 2 つ（平らな向き 1 ずつ）。
- 巻き ± の対 → 2。
- 同じ形の塊 2 つ → 一致 1 組。大きさが違えば 0。
- 自由な重い波 → 振動数 √(m² + 4sin²(k/2)) を見つける。
- エネルギーの内訳の和 ＝ 全エネルギー。
- 箱全体がひとつの領域 → 1。

途中で直した数え方の誤り（どれも、比べる run を回す前に直して回し直した）：
- 中庸の谷の中の点を「谷の間」と数えていた。
- 箱全体がひとつの領域のとき、0 と数えていた。
- 頂上にちょうど止まった点を谷にしていた。
- まばらな円の谷を多数の谷に分けていた。
- 厚い壁ごしの出会いを数えられなかった。
- 塊をフレームの間隔 20 で追っていたため、熱い箱で別の塊をつないでいた。

**熱い始まりのボーズ分布の指数が ω/T で、ħω/T になっていなかった物理の誤りも見つけて直した**（古典の極限 ⟨|φ_k|²⟩ = T/ω² が ħ によらないことをテストに足した）。

読み（3D）：
1. **差は同じくらいの時刻（t≈60〜80）に生まれた**。量子の揺らぎ（ħ=1e-4）が、山の頂上で不安定な長い波として育つ。これは既知。
2. **陰陽＋中庸は、冷たい始まり（量子の揺らぎだけ）では壊れない**。φ=0 そのものが谷なので、揺らぎは中庸の谷の中で揺れるだけ。閉じた箱でも膨張でも、3D でも 2D でも同じ（seed 2 つずつ）。
3. **熱い陰陽＋中庸では、3 つの谷が全部現れた。ところが − と + は一度も直接出会わない**。
   - 出会いの種類の記録（20 時間ごと）で、0-2（− と +）はどの時刻にも 0（3D・2D、閉じた箱・膨張の 4 本、計 86 時刻）。± が触れる所は、必ず中庸をはさんだ 3 つの出会い（0-1-2）か、中庸との出会い（0-1・1-2）だった。
   - これはポテンシャルの形（− から + への道が φ=0 の谷を通る）から予想できることで、発見とは言わない。起きたこととして記録する。
4. **熱い陰陽＋中庸を膨張で冷やすと、中庸だけが残った**。3 つの谷の深さはすべて同じ（V=0）なのに、中庸が選ばれた。
   - 中庸の谷は ± の谷より 4 倍柔らかい（m² 0.025 対 0.1）。熱い揺らぎの自由エネルギーは柔らかい谷ほど低いことが知られているので、その効果と考えられる（推測。測っていない）。
5. 3 つ対等では、3 つの谷の領域が出会う所が一時できた。しかし 96³ の箱では領域が数個しかできず、t≈160 までにひとつの谷が箱の 9 割以上を占めた。**3D の箱は、3 つの谷の網の行く末を見るには小さい**（領域の大きさ約 40 マス対箱 96 マス）。
6. 光があると、位相の巻き（磁束の糸）がほかより長く残った（閉じた箱の t=400 で 76・0。膨張で 238）。
   - エネルギーの 3 割以上が光のような場に移った。
   - 磁場の帯は ω≈0.38〜0.41。「光が重くなる」値 √(2e²⟨|φ|²⟩) ≈ 0.39 と合う（ヒッグス機構。既知の確認）。
7. 熱い連続＋光（閉じた箱）は、T0=0.5 では対称が戻ったまま壊れなかった（既知の、熱による対称性の回復）。
8. **閉じた箱では、どの条件でも 100 時間以上生きた塊は 0**。塊は数千〜2 万回生まれては消えた（熱い波の山）。
   - 長く生きた塊は、膨張した宇宙でだけ 1〜4 個見つかった（陰陽・3 つ対等・連続＋光）。その正体は §6 で確かめる。

4. 陰陽＋中庸の 3 つの結果（冷たいと壊れない／熱いと − と + が直接出会わない／冷えると中庸だけ）は、3D と 2D で同じだった。

## 6. 膨張した 3D で長く生きた塊の正体

3D の膨張した 3 本（陰陽・3 つ対等・連続＋光、seed 1）を、塊の中の谷と巻きを記録する形で回し直した。
- 同じ仕様・同じ seed なので、最後の状態の sha256 は 3 本とも前の run と一致した（決定性）。
- 追った塊について、census の時刻（20 ごと）に、塊の中の点がどの谷にあるか（−1 は谷の間）と、位相の巻きの数を記録した。

| 条件 | 長く生きた塊 | 大きさ（マス） | 動き（寿命のあいだの正味の移動） | 中身（census の時刻ごと） |
|---|---|---|---|---|
| 陰陽・膨張 | 2（寿命 182・115、どちらも最後まで生きていた） | 約 1100〜1150 | 10〜13 マス（ほぼ止まっている） | 谷 0 と「谷の間」が時刻ごとに入れ替わる。反対の谷（谷 1）の点はほぼない（0〜36） |
| 3 つ対等・膨張 | 2（寿命 133・104） | 約 1700〜2000 | 8〜31 マス | 同じく、ひとつの谷（谷 0）と「谷の間」が入れ替わる。ほかの谷の点はわずか（0〜170） |
| 連続＋光・膨張 | 3（寿命 161・126・126） | 約 770〜780 | 3〜10 マス | ひとつの谷と「谷の間」が入れ替わる。**位相の巻きは 18 記録中 14 で 0**（残りの 4 記録で 18〜44：近くを糸が通った時刻） |

読み：
- 3 本とも、長く生きた塊は「反対の谷の泡が縮んでいく途中」ではなかった。
- 同じ谷の中で、場が谷と山の頂上の側を行き来して大きく振動する、局在した塊だった（φ⁴ のオシロンと同じ形。既知）。
- 光のある宇宙でも、ほとんどの時刻で巻きを持たなかった。3D で長く生きたのは渦の糸ではなく、振動する塊だった。
  - 2D の光のある宇宙では、長く生きた塊はほぼすべて巻き 1 の渦だった（§5）。ここは 3D と 2D で違う。
- 3D の閉じた箱では、どの形でも、100 時間以上生きた塊は 0（3D の 24 本のうち、閉じた箱の 12 本）。2D の閉じた箱では、光のある宇宙の渦だけが長く生きた。
  - 閉じた箱は熱い波で満ちているので、塊が壊されるのかもしれない（推測。測っていない）。
  - 膨張は波を薄める（共形時間では、質量のある場の振幅が a とともに変わる）。
- 振動の周波数（ω < m か）は、この記録（20 ごと）では測れない。次に測る候補。

## 7. 「雪の結晶」の問い：全く同じものはあるか

- 27 マス以上の領域について、同じ谷の領域どうしの一致を調べた。対象は、すべての run の、大きい領域が最も多い時刻。
  - 1e-9 以内で一致する組は、どの条件でも **0**。
  - 最も近い組の相対差は、2D で 0.0003〜0.012、3D で 0.01〜4。
- ただし、**これは「3 つ」の効果ではない**。陰陽（2 つ）でも一致は 0 で、最も近い組の差も同じくらい（2D で 0.0004〜0.003。3 つ対等は 0.0008〜0.012）。
  - ランダムな揺らぎから育つ領域は、どの形の宇宙でも 1 つ 1 つ違う。
  - 今回の測り方（大きさと慣性モーメント）では、「3 つで始まると、2 つより違いが増える」という差は見えなかった。
- 3 つで始まる宇宙にだけあったのは、次の 2 つ。
  - 3 つの谷が出会う所（3 つ対等の網の結び目。陰陽＋中庸では、± がいつも中庸をはさんで出会う所）。
  - 3 つ対等の網の結び目の位相の巻き（2D で最後まで 28〜40）。
- 「分かれ続けるか」（領域の中に領域）は、今回の中身（1 段階の谷）では起きようがない。2 段階の形（`cascade`：円 × ±）は仕様と数え方のテストまでで、比べる run は回していない（次の候補）。

## 8. 帯（ω–k）

- 小さい k の振動数は、それぞれの谷の質量とほぼ合った。
  - 実数の場・|φ|²：0.25〜0.31（谷の質量 √λ v = 0.316。熱い場では少し下がる）。
  - 陰陽＋中庸（中庸の谷）：0.157（中庸の谷の質量 √0.025 = 0.158）。
  - 光のある場の磁場：0.38〜0.41（光の質量 √(2e²⟨|φ|²⟩)）。
  - 膨張した宇宙では、共形時間の振動数が a 倍になる（0.53〜0.56 ≈ 0.28 × 2）。
- 帯の数：同じ場の中で、枝が 1 本より多く分かれる様子は、この分解能（Δω = 0.031）では見えなかった。
  - 複数の帯は、場の種類ごと（|φ|² と磁場）に別の質量として現れた。
  - 最初のビン（ω≈0.03）の山は、領域がゆっくり動くことによるもので、帯ではない。
- すべて既知の自由な波・ヒッグス機構の確認。

## 10. 限界

- **量子の場ではない**。古典統計の近似（truncated Wigner）。量子は t=0 の揺らぎとしてだけ入る。粒子の数が多い（強い場の）領域の近似。
  - 本物の量子（小さな 1 次元の鎖を厳密に解く）は次の段。
- 格子（dx=1）と有限の周期箱。
  - 3D の箱 96 マスは、最初の領域の大きさ（約 40 マス）の 2.4 倍しかない。3D の「その後」は箱の大きさで止まっている。
  - 谷の芯は約 3 マス（方針の 6 マスに届かない）。格子の形が形に写る可能性を、解像度を変えて確かめていない。
- 膨張は a≈2.1 まで（格子の分解能で止めた）。宇宙論の膨張の、ごく最初だけ。
- T=400 は、谷の質量の周期（約 20）の 20 倍。長い時間の振る舞いは見ていない。
- 熱い始まりは T0 = 0.5 の 1 点、seed 1。
- 帯の測定は、最後の 200 時間・軸方向の波だけ。分解能 Δω = 0.031。
- 「全く同じか」の比較は、大きさと慣性モーメントだけ。形の細部（境目の凹凸）は比べていない。
- 「長く生きた塊」の追跡は、平均＋3σ の塊を 2 時間ごとに、光の速さの範囲でつないだもの。閾値と間隔は置いた。
