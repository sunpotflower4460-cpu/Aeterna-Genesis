## 2. 読み方（interpretive）
- **3D の糸**：糸は「芯と、量子化された磁束を持つ線」として置かずに生まれる（L2 の 3D 版）。ただし、この箱では残らない。
  - t=0 では、どの断面を通る磁束も 0（θ=0 から始まり、コンパクトな U(1) では e=0.3 の単極子はまず出ない）。そのため、箱を一周する糸も必ず逆向きの相棒と対になり、輪は縮んで消え、対は出会って消える。
  - 箱（トーラス）を一周した糸は縮めないので、長く生き残った（B4）。それでも、相棒と出会えば消える。
  - 「消えない糸」をつくるには、トーラスの穴に正味の磁束を置く（トポロジーで守る。置いたもの）か、宇宙の膨張のように糸が出会えなくする仕組みが要る。次の段の提案（T1）。
- **渦どうしの力**：白が「正しい物理」を持っていることの確認で、新しい発見ではない。第 2 種（既定の β=2）では同じ向きの渦が離れていくので、2D で渦が固まって塊（個体）になることはない。塊をつくるには、第 1 種（β<1）で引き合う側を試すことになる。
- **光円錐が先の白**：順序（誰が誰に影響できるか）と密度だけから、振動する波（½J₀）が育った。ただし、順序はミンコフスキー時空に点をまいて作ったので、ローレンツ不変性は点のまき方の段階で入っている（置いたもの）。「順序だけの宇宙」（推移的パーコレーション）で試すのは次の段。

## 3. 限界・弱点
- **3D**：
  - 箱は 40³・64³・96³ で、seed は 1〜3。トーラスを一周する対は 11 run 中 1 run だけで、頻度は言えない。
  - 冷やす γ（置いたもの）は 0 と 0.01 だけ。β=2 だけ。
  - 糸の長さは「貫かれたプラケットの数」で、斜めの糸は長めに数える（格子の数え方）。
  - |φ| が落ちる途中（t≈20〜40）の数は、ノイズの巻きを含むので意味がない。平均の |φ| が 0.5 を超えてから数えた。
  - ラボの higgs-3d は 32³ と小さく、糸はすぐ消える。見る用で、測る用ではない。
- **磁束の測り方**：3D の最初の版の「Σ|磁束|/(2π·長さ)」は、光（放射）の分まで全体から数えていた。そのため、糸が細くなると 5 を超え、意味を持たなかった。これを捨て、断面ごとに一番近い貫通点へ面を割り当てて、1 本ずつの磁束を測る方法に変えた（テストあり）。ラボの測定値も「糸の長さあたりの磁束」をやめ、「箱を一周している向きの数」にした。
- **渦の力**：
  - 距離は巻き数の位置（格子の点）で測った。1 未満の違いは分からない。
  - β=0.25 では、一度 1 まで近づいてから 3 に戻った。格子に引っかかった可能性があるが、確かめていない。
  - β=1 のわずかな離れ（6→8）が格子の効果かどうかも、確かめていない。
  - 周期箱のため、反対向きの 2 つを半分の箱だけ離して置いた（置いたもの）。
- **因果集合**：2D だけ。点はミンコフスキーのダイヤモンドにまいた。
  - B の揺らぎは大きく、1 回の散布では使えない。
  - テストの許容幅は「平均 ± 3 sem ＋ 0.5」と符号の確認で、ゆるい。
  - 時間発展（B を使って未来を解く）は未着手。

## 5. 次の一手（提案。うえきさんの「トーラスを考え方に入れたら？」から）
