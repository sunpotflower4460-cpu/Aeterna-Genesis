## 1. やったこと

法則（P17 から h を外し、溶けている物の拡散に分配の項を足した）：

```
m    = (1 + c)/2                                                    材料の割合
X_t  = s D_X [∇²X − aff ∇·(X ∇m)] + 反応        X ∈ {U, V1, V2}（aff は 3 つに同じ）
Vi_t = … + s U Vi² − s (F + k) Vi                                  k はどこでも同じ（h=0）
U_t  = … − s U (V1² + V2²) + s F (1 − U)
c_t  = M ∇²(c³ − c − κ∇²c − back·aff (U+V1+V2)/2) + y s k (V1+V2)(1 − c) − s F (1 + c)
```

- 分配の項は、溶けている物 X の自由エネルギー −aff·X·m から出る流れ J = −D(∇X − aff X ∇m)。釣り合うと X ∝ e^{aff·m}（中は外の e^{aff} 倍）。油と水に物が分かれるのと同じ一般的な物理。
- 同じ自由エネルギーから、材料の化学ポテンシャルに −aff(U+V)/2 が入る（作用・反作用、back=1）。back=0 は対照だけ。
- **「材料が中身を助ける」とはどこにも書いていない。** aff は餌と 2 種の自己複製に同じで、分解の速さ k は材料の中でも外でも同じ。
- 離散化：∇·(X∇m) = ½[∇²(Xm) − m∇²X + X∇²m]。5 点／7 点の ∇² では、面の平均の流れ ½Σ(X_i+X_j)(m_j−m_i) と完全に一致し、量を保存する（テスト）。局所・明示的オイラー・周期境界。FFT は裏付けにだけ使う。
- t=0 は P15・P17 と同じ（材料はどこにもない c=−1＋ノイズ、種 12 個は V1・V2 のランダムな混ざり）。

### 依存の測り方（`tools/protocell_dependence.py`）

1. **材料なしの対照**：同じ t=0 で、材料が一度もできない run（y=0・back=0・c のノイズ 0 → c ≡ −1 がちょうど保たれ、分配の項はちょうど 0）。依存の強さ **D_y = 1 − V(材料なし)/V(材料あり)**（t=T の自己複製の平均の濃さ）。分類（DEAD = 1e-4）：
   - 「全滅」：材料ありでも V<DEAD。
   - **「依存」：材料なしの対照が全滅し（V<DEAD）、材料ありは生きる**。材料がないと生きられない。
   - 「強く増える」：材料なしも生き残るが、D_y>0.5（材料があると 2 倍以上）。助けにはなるが、なくても生きられる。
   - 「どこでも生きる」：それ以外。
   - （最初は D_y>0.5 だけで「依存」と呼んでいた。レビューで、材料なしが生き残る点を「依存」と呼ぶのは言い過ぎと指摘され、分類を分けた。）
   - 最初は「y=0 だけ」を対照にしていたが、aff>0 では溶けている物の反作用で c が ±0.05 動き、「材料なし」にならなかった（2D で確かめた）。対照を上のように直し、「材料なしでは、どの aff でもまったく同じ run になる」ことをテストした。地図の最初の 36 点は、この同一性から aff=0 の run を対照に使った（記録に `control` と旧値 `v_without_y0_backreact` を残した）。
2. **ノックアウト**：t0=200 で分岐し、片方だけ材料を溶かす（c=−1＋新しいノイズ）。
   - 材料を作り直せる場合（法則そのまま）と、**二度と作れない場合**（`--no_remake`：t0 から材料なしの対照と同じ法則）。
3. **中身を取り除く**（既存の `--kill`）：逆向き。入れ物は洗い流されるか。

## 3. 読み方（interpretive）

- **P17 では「材料が中身を守る」と書いた（h）。P18 では書いていない。** 書いたのは「溶けている物はどれも材料に少し溶けやすい」という、中身にとって良いか悪いかを決めない性質だけ。結果として、材料は**餌が集まるポケット**になり、出会いの法則（U V²）で中の自己複製が速く増え、水の中だけでは生きられない厳しさでも生き残れる。この「守る」向きは、法則からの帰結として測られた。
- 反対の向きもありうることは、対照が示す：中身だけが材料に集まる場合（aff_U=0）は、3D で全滅した。分配が中身を助けるとは限らない。
- 依存の中身は「材料があると生きられる」であって、「特定の 1 つの入れ物がないと死ぬ」ではない：材料を溶かしても、中身がすぐに作り直す（B5）。**材料を作れなくしたときだけ死ぬ**（B6）。これは生き物の「自分で作るものに頼っている」に近い形。
- 3D と 2D：どちらも同じ形の帯（強く増える → 依存 → 全滅）。依存の帯は 3D の方が広い（約 1.27 倍 対 約 1.16 倍）。3D の主な点（k=0.080）は依存、2D の主な点（k=0.070）は強く増える側で、2D の依存の点（k=0.074）は入れ物が少ない（8〜11）。3D の方が中と外の比が高く（13 対 9〜11、k=0.070）、点が入れ物の奥にある（最小 0.71 対 0.52）。

## 4. 限界・弱点

- **aff（材料の溶かす力）は置いた**。全部の溶けている物に同じ値なので「中身を特別に助ける規則」ではないが、材料の相が物を溶かしこむ性質は置いた。aff=0 では依存は現れない。
- **y（壊れた残りが材料になる）は、置いた生成の規則として残る**。量の保存ではない：生成の項 y s k V (1−c) = 2y s k V (1−m) は、材料が満ちる（m→1）と 0 になり、その分の壊れた自己複製は材料にならずに消える。壊れた量のうち材料になった割合（1−m で重み付け）は、既定の run で 0.52（2D 128²、T=400）・0.49（3D 32³、T=200）。つまり壊れた自己複製の約半分は材料にならずに消えている。「中身が材料を作る」向きは、この規則として法則に書いたまま。
- **依存は環境の厳しさ k の性質でもある**：水だけで生きられる k では、材料は「増やす」だけ（D 0.2〜0.5）か「強く増やす」（2 倍以上）。依存（材料なしでは全滅）は、水だけでは全滅する k（3D 0.075 以上、2D 0.074 以上）でしか現れない。k は 1 点に選ばず走査し、帯の幅（3D 約 1.27 倍、2D 約 1.16 倍）を報告した。
- 地図は 1 seed、32³（3D）・128²（2D）、T=200。帯の端は粗い（k の刻み 0.0025〜0.005）。
- 境界は相の境目で、薄い膜ではない（P15・P17 と同じ）。
- aff=1 以上では閉じた玉の割合が下がり（B9）、aff=2 では入れ物がくっつく（A4）。
- 解像度と数値の裏付けは §6・§6b。

## 5. 法則変更の監査（`mutation_type: law_variant`）

- 新しいファイル `genesis/models/protocell_partition.py` で、既存のモデルは変えていない。
- 何が変わったか：P17 から h を外し（k' → k）、分配の項（aff）と、その作用・反作用（back）を足した。g0 はない（g≡1）。
- 対照用の任意のつまみ `aff_U`・`aff_V`（なければ aff）は、既定の動作を変えない。
- 置いたもの：Gray–Scott の化学と流れ（F、k、s、D）、壊れた残りが材料になる y、材料が水と混ざらない（Cahn–Hilliard の M・κ）、分配 aff、t=0 の種。
- 置いていないもの：入れ物の形・数・場所、材料が中身を守る規則（h）、中で増えやすい規則（g0）、依存の向き。
- 第 8 監査：**「材料 → 中身」の向きは、法則に書かずに測定で現れた（B1・B6・B10）。「中身 → 材料」の向き（y）は、頭打ちのある生成の規則として書いたまま（量の保存とは言えない）**。お互いの依存のうち、片方が育ち、片方は置いた。

## 6b. 解像度（同じ物理の箱を細かくする。`tools/protocell_resolution.py --model partition`）

dt ∝ dx⁴、種の半径は物理の長さで一定、t=0 のノイズは物理の体積あたり同じ強さ。seed 1〜3、同じ法則。判定は P17 と同じ（すべての dx の組で、平均の差が seed の幅以内か相対 15% 以内）。

**3D（先に）**：L=32（32³・40³・48³）、T=200、既定（aff 0.5、k 0.080）

| 量 | dx=1 | dx=0.8 | dx=2/3 | 判定 |
|---|---|---|---|---|
| 入れ物の数密度（×10⁻⁴） | 2.65 [2.14–3.05] | 2.54 [2.14–3.05] | 2.65 [1.83–3.05] | 依存しない（rel 0.04） |
| 箱の中の割合 | 0.096 | 0.099 | 0.095 | 依存しない（0.04） |
| 中と外の比 | 13.4 | 12.4 | 12.7 | 依存しない（0.08） |
| 1 つに 1 つ（多数の割り当て） | 1.0 | 1.0 | 1.0 | 依存しない |
| 閉じた玉の割合 | 1.0 | 0.95 | 1.0 | 依存しない |
| 分裂の数（箱あたり 0〜2 回） | 4 回 | 2 回 | 2 回 | 数が少なすぎる（判定は「依存しない」だが、根拠は弱い） |
| 受け継ぎ | 1.0 | 1.0 | 1.0 | 判定なし（分裂 0 回の seed がある） |

**2D（そのあと）**：L=128（128²・160²・192²）、T=400、既定（aff 0.5、k 0.070）

| 量 | dx=1 | dx=0.8 | dx=2/3 | 判定 |
|---|---|---|---|---|
| 入れ物の数密度（×10⁻³） | 6.33 | 5.60 | 5.90 | 依存しない（rel 0.12） |
| 箱の中の割合 | 0.135 | 0.119 | 0.126 | 依存しない（0.13） |
| 中と外の比 | 9.7 | 10.8 | 9.8 | 依存しない（0.11） |
| 1 つに 1 つ | 0.986 | 0.993 | 0.990 | 依存しない |
| 分裂の数密度（×10⁻³） | 5.64 | 5.01 | 5.21 | 依存しない（0.12） |
| 受け継ぎ | 1.0 | 1.0 | 1.0 | 依存しない |

- **2D の k=0.070 の分類は解像度で変わる**（dx=2/3、192²、T=400）：材料ありの V は 0.098・0.090・0.102、材料なしでは 3/3 で 0（dx=1 では 0.0014・0.0007・0.0007 と生き残る）。dx=1 では「強く増える」、dx=2/3 では「依存」。この点は依存の境目の近くで、分類は格子に敏感と書く。2D の依存の点 k=0.074 の解像度は確かめていない。
- 3D の分裂は、この箱（L=32、T=200）では少なく（0〜2 回）、解像度の判定の根拠にならない。P17 で見えた「細かくすると分裂が減る」傾向（9→8→4）は、ここでは 4→2→2 回で、数が少なすぎて確かめられない（candidate のまま）。
- 界面の幅あたりのセル数は dx=1 で約 1.4、dx=2/3 で約 2.1（CH の √(2κ)≈1.4）。docs/3D_NATIVE_POLICY.md の 6 には届かない（P17 と同じ限界）。

## 7. 規律チェック

- [x] 3D を先に、そのあと 2D。報告も 3D が先。
- [x] 既存のモデル・測定器は、既定の動作を変えていない（新しいファイルと、任意の引数だけ）。

- [x] 対照：aff=0（D=0、式から）、材料なし（c ≡ −1）、back=0、aff_U=0・aff_V=0、kill、ノックアウト 2 種。
- [x] 最初の対照の誤り（y=0 だけでは材料なしにならない）を見つけ、直し、テストした。
- [x] はしご R4 の記録を更新し、`python tools/ladder.py --check` を通した。段は動かしていない（薄い膜ではないため）。
- [x] 研究データは削除していない。
- [x] **no_touch**：主な証拠（地図、3D の主な点 B1〜B4・B8・B9、2D の C1〜C4・C7、解像度、局所 vs スペクトル）は、すべて t=0 から法則だけで回した run（途中で手を入れていない）。途中で手を入れたのは、はっきり介入として書いた次のものだけ：ノックアウト（t0=200 で材料を溶かす B5・C5、材料を二度と作れなくする B6・C5）と、中身を取り除く kill（B7、t=250）。
