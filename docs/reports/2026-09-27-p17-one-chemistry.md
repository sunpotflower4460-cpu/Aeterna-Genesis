## 1. やったこと

法則（P14・P15 と同じ 2 つの自己複製 V1・V2 と餌 U に、材料の割合 m=(1+c)/2 を足した）：

```
k'   = k (1 − h·m)                                   分解には水がいる（材料の中では h だけ遅い）
Vi_t = s Dv ∇²Vi + s U Vi² − s (F + k') Vi
U_t  = s Du ∇²U − s U (V1² + V2²) + s F (1 − U)
c_t  = M ∇²(c³ − c − κ∇²c) + y s k' (V1+V2)(1 − c) − s F (1 + c)
```

P15 から置きかえた 3 つ：

| P15 で置いた規則 | P17 での置きかえ | 残った数 |
|---|---|---|
| 自己複製が材料を作る α | 自己複製の分解（Gray–Scott の k の項）の残りが材料になる | y：壊れた 1 つから材料がいくつできるか（化学量論の数） |
| 材料が壊れる β | 流れの反応器で、全員と同じ F で洗い流される | なし |
| 中の方が増えやすい g0=0.9 | なし（g≡1）。代わりに、分解（加水分解）には水がいる | h：材料の中で分解がどれだけ遅いか |

- 係数：
  - 3D：F=0.03、k=0.070、y=2、h=0.1、κ=1、M=1、s=10、dt=0.01、48³
  - 2D：F=0.035、k=0.066、y=2、h=0.1、dt=0.02、128²
- k は、水の中だけでは自己複製が増え続けられない値として選んだ（材料なしの走査。3D 32³）。
  - k=0.066・0.068 では増えた（点 19〜20）。
  - k=0.070 では点が 3 つで止まった。k=0.073 では 1 つになった。
  - 2D（128²）では、k=0.064 で増え、0.066 で点が 5 つで止まった。
- t=0 は P15 と同じ。材料はどこにもなく（c=−1＋ノイズ 0.02）、種は 12 個で、それぞれ V1 と V2 のランダムな混ざり。
- 測り方は P15 と同じ `tools/protocell_run.py`（25 時間ごと）。入れ物の外にある点の数も数えた。

## 3. 読み方（interpretive）
- 段 A（h=0）：材料が中身の壊れた残りなら、別の規則を置かなくても、1 つの点に 1 つの入れ物ができた。ただし、それは中身の影で、中身は入れ物がなくても同じように生きた。
  - P15 で「お互いが必要」に見えたうち、「中身が入れ物を必要とする」側は、置いた g0 から来ていた。
- 段 B（h=0.1）：分解に水がいるという 1 つの化学の性質で、中身が自分の作った入れ物を必要とするようになった。材料の中では分解が少し遅く、その 1 割の差で、水の中だけでは止まる自己複製が増え続けた。
  - 入れ物と中身の「お互いの依存」は、別々に置いた規則ではなく、同じ反応（分解）の両面から生まれた。
    - 分解の残りが材料になる。
    - 材料の中では分解が遅い。
  - これは、P15 で置いた 3 つの規則を置かずに済んだという意味で、置いたものを減らせた。ただし、h・y・k は数として選んだ（次の節）。
- 3D と 2D：同じ形で通った。3D の方が中と外の差が大きく（約 8 と約 5）、入れ物の数は少ない（箱の大きさの違いもある）。

## 4. 限界・弱点
- 置いた数が残っている。
  - **k**：水の中だけでは増え続けられない値。境目のすぐ上を選んだ（3D 0.070、2D 0.066）。
  - **h=0.1**：窓は狭い。h=0.3 以上では入れ物がくっついて大きな塊になった（32³ の下見）。窓の広さ（どこまで下げられるか）は、0.1 と 0.15 しか測っていない。
  - **y=2**：y=1 では材料が足りない。
  - P15 の g0=0.9 が「ぎりぎり」を選んだのと同じ種類の選び方で、それを化学の性質（水がいる）に言いかえた、というのが正確なところ。
- 材料が水と混ざらない性質（Cahn–Hilliard の κ・M）は置いた。M=4 は明示的オイラーで不安定だった。
- 境界は相の境目で、薄い膜ではない。中身は外にしみ出す（比 5〜8）。どの点も境目をまたぎ、中にあるマスは点の 5〜6 割（§6）。
- seed は 3 つ。対照は 1 seed。h の窓の 0.3 以上は 32³ の 1 seed だけ。
- 入れ物の数は、3D では 24〜35 で頭打ちになった（48³ の箱）。
- 解像度（§6b）：割合・比・1 つに 1 つ・受け継ぎ・閉じた玉は dx 1〜2/3 で変わらなかった。3D の分裂の数は細かくすると減り、格子の幅に依存する可能性がある。界面は方針より粗い（2.1 セル以下）。
- 3D の監査と画像は、最初の版では最後のフレームより 1 step 先の状態を見ていた（レビューの指摘）。いまは最後のフレームと同じ状態を見る（テスト）。

## 5. 法則変更の監査（`mutation_type: law_variant`、docs/AI_EXPERIMENT_POLICY.md §4）
P17 はパラメータの探索ではなく、法則の変更（P15 の α・β・g0 の項を、分解の残り・洗い流し・水のいる分解に置きかえた）。H17 に `mutation_type: law_variant` を付けた。

| 項目 | 確かめたこと |
|---|---|
| 物理的由来 | 分解（加水分解）の残りが材料になる、流れの反応器では全員が同じ F で洗い流される、加水分解は水を使うので水の少ない所で遅い。どれも化学として普通の性質 |
| 対称性 | V1 と V2 を入れかえても法則は同じ（ビット単位、テスト）。格子の軸の入れかえ・平行移動に対して同じ（局所の等方な 5 点・7 点） |
| 次元整合性 | どの項も「1/時間」の速さ。s は時計の倍率で、Gray–Scott の項（F・k・U V²）と材料の源（y s k' V）は同じ時計で動く。y・h・m は次元のない数。Cahn–Hilliard の項は M=1・κ=1 の単位で、P15 と同じ |
| 保存則 | 反応と流れのない極限（F=0、種なし）では、材料 ∫c は丸め誤差まで保存される（テスト `test_without_flow_and_reactions_the_material_is_conserved`）。反応と流れのある系は開いた系で、保存量はない（P14・P15 と同じ）。y=2 は「壊れた 1 つから材料 2 単位」という数え方で、質量の単位をそろえた主張ではない |
| 熱力学整合性 | Cahn–Hilliard の部分には下がり続ける自由エネルギーがある。反応は流れ（餌の供給）で平衡から離された開いた系で、自己触媒は不可逆の理想化（Gray–Scott と同じ）。水のいる分解は、速さを下げるだけで、エネルギーを外から足さない |
| 既知極限 | h=0 のとき、自己複製と餌の式は材料を含まず、P14 の Gray–Scott と同じ（テスト `test_without_hydrolysis_the_replicators_never_feel_the_material`）。種がなければ何も起きない（テスト）。y=0 では材料が作られず、c は −1 に戻る |
| 第 8 監査 | 入れ物の数・形・場所、1 つに 1 つ、中と外の差、分裂、受け継ぎ、中身が入れ物を必要とすることは、式にも t=0 にも入れていない（§7） |

## 6. 数値の裏付けと 3D の監査
- **局所 vs スペクトル**（`genesis/diagnostics/corroborate_protocell.py`、テスト `tests/test_corroborate_protocell.py`）：
  - 同じ t=0 から、局所の 5 点・7 点（dt）と FFT のラプラシアン（dt/8）で回した。
  - 比べたもの：入れ物の数、箱の中の入れ物の割合、自己複製の平均、中と外の比。
  - 2D（64²、t=150）：入れ物 22 と 20、差は最大 4.8%。
  - 3D（32³、t=150）：入れ物 11 と 10、差は最大 4.8%。
  - 3D（24³、t=100）：入れ物 2 と 1（数が少なすぎて比べられない）、ほかの 3 つの差は 4.4% 以内。テストでは使わない。
  - テスト（slow）は 3D を 32³・t=100 にし、判定 `corroborated`（入れ物の数を含む 4 つ）をそのまま確かめる。結果：入れ物 10 と 8、箱の中の割合・自己複製・中と外の比の差は 1.3% 以内（入れ物の数の差 |a−b|/(a+b) は 0.11、許容は 0.2）。
  - 結論：入れ物は格子の差分の作り物ではない。
  - FFT の方は dt/4 では発散した（∇⁴ の固有値が大きいため）。
- **3D の監査**（`tools/protocell_run.py` の `three_d_audit`、3D の run の最後に記録）：
  - 材料と自己複製の場に `three_d_authenticity` をかけた。
  - 3D でしか意味のない不変量として、入れ物 1 つずつのベッチ数（b0・b1・b2）と、箱を貫くかどうかを測った。閉じた玉は (1, 0, 0) で、箱を貫かない。
  - テスト `test_the_3d_audit_sees_closed_balls`：周期の端で切れた玉を 1 つの閉じた玉と読み、平らな板は玉と読まない。
  - 結果（3D、48³、h=0.1、seed 1〜3、t=400）：
    - 材料・自己複製とも `genuinely_3d = True`（z 方向の変化の割合 0.10〜0.12）。
    - 入れ物 83 個のうち 81 個が閉じた玉 (1, 0, 0) だった。残りの 2 個（seed 2・3 に 1 個ずつ）は細長い入れ物で、トンネルを 1 つ持つ (1, 1, 0)。
    - 箱を貫く入れ物は 0。どの入れ物も、3 方向とも 6 マス以上の広がりを持つ。
- **入れ物の外の点**：
  - 最初の版は、点が 1 マスでも入れ物に触れていれば「中」と数えていた（レビューの指摘）。
  - いまは、点のマスの半分以上が入れ物の外にあるときに「外」と数える。あわせて、境目をまたぐ点の数と、中にあるマスの割合の最小値も記録する。
  - その結果、「外の点 0」は 3D では変わらなかった（マスの半分以上が外の点 0）。2D では 2,712 の点・コマのうち 9 で、点のマスの半分以上が外にあった。
  - どの点も入れ物の境目をまたいでいる。入れ物（c>0）は点の芯で、点の裾は外にある。これは「中身が外にしみ出す」（§4）と同じこと。

## 6b. 解像度（同じ物理の箱を細かくする。`tools/protocell_resolution.py`）
- 物理の箱の大きさ L は変えずに、格子の幅 dx だけを 1・0.8・2/3 に変えた。
  - 格子の数は n=L/dx。
  - dt は dx⁴ に比例させた（∇⁴ の安定条件）。
  - 種の半径は物理の長さのまま（3）。
  - dx=1 のときは、いまのモデルとビット単位で同じ（確認済み）。
- 種の置き場所はセル単位の乱数で決まるので、dx が違うと同じ seed でも t=0 は同じにならない。そのため、1 本ずつではなく、seed 1〜3 の平均と幅で比べた。

**3D（先に）**：L=32（32³・40³・48³）、T=200

| 量 | dx=1 | dx=0.8 | dx=2/3 |
|---|---|---|---|
| 入れ物の数（t=200） | 11・8・9 | 9・8・10 | 8・8・8 |
| 箱の中の入れ物の割合 | 0.093 | 0.087 | 0.091 |
| 中と外の比（後半） | 8.4 | 8.9 | 8.5 |
| 1 つに 1 つ | 1.0 | 1.0 | 1.0 |
| 分裂（3 seed の合計） | 9 | 8 | 4 |
| 受け継ぎ | 9/9 | 8/8 | 4/4 |
| 閉じた玉の割合 | 1.0 | 1.0 | 1.0 |

**2D（そのあと）**：L=128（128²・160²・192²）、T=400

| 量 | dx=1 | dx=0.8 | dx=2/3 |
|---|---|---|---|
| 入れ物の数（t=400） | 103〜106 | 81〜106 | 98〜100 |
| 箱の中の入れ物の割合 | 0.146 | 0.140 | 0.143 |
| 中と外の比（後半） | 4.8 | 5.4 | 4.9 |
| 1 つに 1 つ | 1.0 | 1.0 | 1.0 |
| 分裂（3 seed の合計） | 275 | 255 | 261 |
| 受け継ぎ | 275/275 | 255/255 | 261/261 |

- 読み：
  - 箱の中の割合・中と外の比・1 つに 1 つ・受け継ぎ・閉じた玉は、dx=1 と 2/3 の差が seed の幅以内か相対 3% 以内だった。この範囲では、格子の幅に依存しない。
  - 入れ物の数は、3D で細かくするとやや減った（9.3 → 8.0。seed の幅以内）。2D では約 5% 以内。
  - **3D の分裂の数は、細かくすると減った（9 → 8 → 4）**。T=200 では分裂が少なく、1 seed は 0 回だった。分裂の数（速さ）は、格子の幅に依存する可能性がある。受け継ぎは、どの dx でも 100%。
- 限界：
  - 界面の幅 √(2κ)≈1.4 は、dx=2/3 でも 2.1 セルで、方針（`docs/3D_NATIVE_POLICY.md` §2）の 6 セルに届かない。
  - 3D の本番の run（48³、dx=1）は Coarse Global の段にあたる。
  - これより細かい格子は、費用が大きく（dt ∝ dx⁴）、行っていない。

## 7. 規律チェック
- **no_touch**：既存のモデル・測定器は変更していない。`protocell_run.py` は、任意の引数と記録の項目を足しただけで、P15 の既定の動作は同じ（`tests/test_protocell.py` が通る）。
- **置いたもの**：
  - Gray–Scott の化学と流れ（F・k・拡散）。
  - 分解の残りが水と混ざらないこと（κ・M）、y、h。
  - t=0 の種。
- **第 8 監査**：入れ物の数・形・場所、1 つに 1 つ、中と外の差、分裂、種類の受け継ぎ、中身が入れ物を必要とすることは、どれも方程式にも初期条件にも入れていない。決定性あり（テスト）。2 つの種類の対称性あり（テスト）。
- **強い言葉**：「細胞ができた」「膜ができた」とは言わない。「相の境目でできた入れ物が、同じ化学から生まれ、中身と互いに必要とし合った」に限る。
