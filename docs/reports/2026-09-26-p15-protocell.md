## 1. やったこと
- 法則（P14 の 2 つの自己複製に、入れ物の材料 c を足した）：
  - `c_t = ∇²(c³ − c − κ∇²c) + α(V1+V2)(1−c) − β(1+c)`
    - c は油と水のように分かれる（Cahn–Hilliard）。入れ物の中が c≈+1、外が c≈−1。
    - 材料は、自己複製がいる所で作られ（α）、どこでも壊れる（β）。
  - 自己複製は、入れ物の中の方がよく写せる：`g(c) = g0 + (1−g0)·clip((1+c)/2, 0, 1)`、g0=0.9。
    - g0=0.9 は、入れ物がないと自己複製が続けにくいぎりぎりの値。2D の探索で、g0=0.9 以下では入れ物なしの点が消えることを確かめた。
  - Gray–Scott の時計を s=10 倍速くした（同じ化学を、入れ物と同じくらいの時間で動かすため）。
  - 係数：
    - 3D：κ=1、α=1、β=0.1、F=0.03、k=0.065、dt=0.01、48³
    - 2D：F=0.035、k=0.062、dt=0.02、128²
  - 局所・明示的オイラー・周期境界。
- **置いたもの**：
  - 「お互いがいないと続かない」関係を、法則として置いた（自己複製が材料を作る／中の方が増えやすい）。
  - 入れ物の形・数・場所は置いていない。**t=0 には入れ物がどこにもない**（c = −1 ＋ ノイズ 0.02）。
  - 種は 12 個で、それぞれ V1 と V2 のランダムな混ざり（P14 と同じ）。
- 測り方（25 時間ごと）：
  - 入れ物（c>0 のつながり、周期でつなぐ）の数、中身のある数、1 つの入れ物にある点の数。
  - 中と外の自己複製の濃さの比。
  - 入れ物の出来事：重なりで前のコマと対応させ、誕生・きれいな分裂・合体・消滅を数える。
  - 1 種類にそろった中身をもつ入れ物の分裂で、子が親の種類を持つか（期待値は P14 と同じ）。
- 対照：
  - `alpha=0`（入れ物の材料を作れない）
  - `--kill 300`（t=300 に自己複製を全部取り除く）

## 3. 読み方（interpretive）
- 「自分の入れ物を自分で作り、その入れ物が自分を助ける」関係を、法則として置いた。すると、置いていない次のことが育った。
  - 入れ物の誕生
  - 1 つに 1 つの中身
  - 内と外の差
  - 中身ごとの分裂と、種類の受け継ぎ
- 中身を取り除くと入れ物は消え、入れ物を作れないと中身は続かない。「お互いがいないと続かない」というまとまり（オートポイエーシスの最も簡単な形）が、測定で確かめられた。
- P14 の点は、3D ではミミズのような管だった。入れ物があると、2D では丸く分かれた区画になった。

## 4. 限界・弱点
- **膜ではなく、相の境界**。入れ物の境は、油と水の境目のような「相の境界」。細胞膜のような薄い二重の膜ではない。中身は外にしみ出す（中と外の比は約 10）。餌 U は自由に出入りする。
- お互いの依存（α・g0）は置いたもの。入れ物が生まれ、分かれることは育ったが、この 2 つの仕組みそのものは置いた。
- 係数は 1 組。α・β・g0 を変えたときの範囲は、2D の探索で一部だけ見た。
  - α=0.5 では、入れ物は 7 個のまま分かれなかった。
  - α=3・β=0.05 では、1 つの大きな入れ物にまとまった。
- 3D は 48³ で、入れ物の数が 13〜14 で頭打ちになる（箱が小さい）。分裂の数が少ない（22 回）。
- seed は 3 つ。対照は 1 seed。
- 違いは 2 種類だけ（P14 と同じ）。新しい違いは生まれない。

## 5. 規律チェック
- **no_touch**：既存のモデル・測定器は変更していない（P14 の `gray_scott_two` の関数を import して使うだけ）。
- **置いたもの**：
  - 法則（κ・α・β・g0・s・F・k・拡散）
  - 2 つの化学があること
  - t=0 の種（ランダムな混ざり）。入れ物は t=0 に 0 個。
- **第 8 監査**：
  - 入れ物の数・形・場所・中身の入り方・分裂・種類の受け継ぎは、方程式にも初期条件にも入れていない。
  - 決定性あり（テスト）。V1 と V2 の対称性（入れ替えてビット単位で一致）もテストした。
- **強い言葉**：「入れ物」「中身」は比喩の少ない言い方を選んだ。細胞・生命・膜（二重膜）とは呼ばない。
