# GENESIS_ROOT — Pure Genesis R0

## 北極星

Aeterna の最上位の研究問いを次に固定する。

> **R0: 何かと何かが区別可能になり、その関係が変わりうる。**
>
> 根拠: 区別・関係・変化が一切なければ前後を区別できず、何らかの宇宙が「生まれる」という出来事そのものを定義できない。

R0 は宇宙の最終的な形而上学的真理だとは主張しない。**現在これ以上削ると「生成」という問い自体を計算できなくなる最小の作業仮説**として置く。将来、より少ない公理で同じ説明力を持つ定式化が見つかれば R0 自身を簡約してよい。

## 一番強いルール — Why Gate

Pure Genesis に新しい「物理的なもの」を追加する前に、必ず次を問う。

1. **なぜそれがあるのか。**
2. R0 からどう導けるのか。
3. それは実験後に観測できるものを、先に入力していないか。
4. それを消しても実験できないのか。
5. 説明できないなら、Pure Genesis の物理前提として採用しない。

そのため、空間・次元・周波数・位相・トーラス・渦・粒子・場・境界・細胞・DNA・神経・脳・記憶などは**最初に置かない**。それらが必要になった場合は、R0 からの時間発展を測ったあとでのみ「候補」として名付ける。

## 宇宙と脳を別レシピにしない

この研究では「宇宙を作るルール」と「脳を作るルール」を別々に置かない。

調べるのは一つだけである。

> **R0 から関係が自ら分化・閉路化・階層化・履歴依存化し、さらにその関係単位どうしが同じ生成を再帰できるか。**

脳は成功ターゲットとして描かない。将来、関係系が記憶・予測・適応などに相当する能力を観測された場合にだけ、独立した厳しい検証を行う。

## 最初の自動実験

`ai_lab.dream.pure_genesis` は固定格子を使わない。物理状態として持つのは**関係行列だけ**で、座標・距離・方向はない。

開始状態は、すべての関係が同じ値を持つ**最大置換対称状態**である。これは「全ての場所が同じ空間」ではなく、そもそも場所を置かず、どの区別も他より特別ではないという意味である。

その後、R0 の「関係は変わりうる」を実験として成立させるため、匿名の一つの関係に最小の変化イベントを一度だけ起こす。どの組が選ばれるか、符号、変化量、有限要素数、更新回数、正規化法は**数値レギュレータ**であって物理主張ではない。これらを変えて同じ結果が残るかを必ず比較する。

### 候補法則の最小文法

自動探索が使える演算は、現在は次の4つだけである。

- `relation_self`: 現在の関係そのもの。
- `relation_composition_2`: 中間の区別を共有する2つの関係の合成。
- `relation_contrast`: すべて同じだった関係から、ある関係が相対的に違うこと。
- `relation_trend`: 前回から今回へどう変わったか。新しい物理場ではなく、R0 の change の履歴差分。

どの組合せが正しいかは**与えない**。小さい候補法則を大量に比較し、有限サイズ・正規化・最初の匿名イベントを変えても残るものを優先する。演算が多い法則には複雑さペナルティをかける。

これら4演算さえ「宇宙の真の法則」とは主張しない。R0 だけから作れる最小候補文法であり、不要な演算は反証で捨てる。

## 後から測るもの

自動実験は、開始時には与えず、発展後にだけ次を測る。

- 関係の差が増えたか。
- 差が持続するか。
- 数値更新上の反復があるか（**まだ物理周波数とは呼ばない**）。
- 関係グラフに閉路ができるか。
- 関係の有効ランクが変わるか。
- 一時的な介入を取り除いた後も履歴差が残るか（**まだ記憶とは呼ばない**）。

空間・物理次元・トーラス・渦・生命・脳は現在のroot実験では**主張しない**。

## 現在の限界を隠さない

関係を実数スカラー行列で表すこと自体は計算表現であり、「宇宙の根源が実数行列である」とは証明していない。有限要素数も宇宙の粒子数ではなく、更新stepも物理時間ではない。正規化も物理法則ではない。

Pure Genesis の目的は、これらの計算上の足場を**物理の前提と取り違えず、結果がそれらに依存しない方向へ一つずつ削っていくこと**である。

## 既存Aeternaとの関係

既存の g001 / X-pattern / Local Vortex Energy / F-path / Deep-Time / Multi-World は捨てない。それらは「すでに空間・法則などを与えたとき、何が起きるか」を精密に測る下流実験として残す。

v8 では各仮説に `root_relevance` を付け、**観測から先に生まれた未知patternを、人間が先に書いた下流ルートより研究上優先しやすくする**。ただし既存の unexplored / breaker / random の最低枠、科学判定、公式Level、Room昇格条件は変更しない。

合言葉は一つ。

> **「それはなぜあるのか。R0から必要になったのか、それとも人間が置いたのか。」**
