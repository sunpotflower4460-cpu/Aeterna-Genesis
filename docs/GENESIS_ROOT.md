# GENESIS_ROOT — Pure Genesis R0

## 北極星

Aeterna の最上位の研究問いを次に固定する。

> **R0: 何かと何かが区別可能になり、その関係が変わりうる。**
>
> 根拠: 区別・関係・変化が一切なければ前後を区別できず、何らかの宇宙が「生まれる」という出来事そのものを定義できない。

R0 は宇宙の最終的な形而上学的真理だとは主張しない。**現在これ以上削ると「生成」という問い自体を計算できなくなる最小の作業仮説**として置く。将来、より少ない公理で同じ説明力を持つ定式化が見つかれば R0 自身を簡約してよい。

## 一番強いルール — Why Gate

Pure Genesis に新しい「物理的なもの」を追加する前に、必ず次を問う。

1. **なぜそれがあるのか。**
2. R0 からどう導けるのか。
3. それは実験後に観測できるものを、先に入力していないか。
4. それを消しても実験できないのか。
5. 説明できないなら、Pure Genesis の物理前提として採用しない。

そのため、空間・次元・周波数・位相・トーラス・渦・粒子・場・境界・細胞・DNA・神経・脳・記憶などは**最初に置かない**。それらが必要になった場合は、R0 からの時間発展を測ったあとでのみ「候補」として名付ける。

## 宇宙と脳を別レシピにしない

この研究では「宇宙を作るルール」と「脳を作るルール」を別々に置かない。

調べるのは一つだけである。

> **R0 から関係が自ら分化・閉路化・階層化・履歴依存化し、さらにその関係単位どうしが同じ生成を再帰できるか。**

脳は成功ターゲットとして描かない。将来、関係系が記憶・予測・適応などに相当する能力を観測された場合にだけ、独立した厳しい検証を行う。

## 最初の自動実験

`ai_lab.dream.pure_genesis` は固定格子を使わない。計算表現として持つのは**関係行列だけ**で、座標・距離・方向は置かない。

開始状態は、すべての関係が同じ値を持つ**最大置換対称状態**である。これは「全ての場所が同じ空間」ではなく、そもそも場所を置かず、どの匿名slotも他より物理的に特別ではないという意味である。

### 匿名slotは「最初から存在する粒子」ではない

有限計算のために N 個の匿名slotを用意するが、**slot番号そのものを物理的な個体・粒子とは数えない**。初期状態では各slotの「他との関係profile」が同一なので、置換すれば区別できない。

物理的な「区別候補」は、発展後に各slotの関係profileをラベル抜きで比較し、異なるprofile classが何種類できたかとして測る。これを **permutation quotient（置換で同じものを同一視する監査）** とする。

したがって、8 slotを計算したから「最初から8個の何かがあった」とは言わない。

### なぜ関係を無方向として始めるのか

R0 は「関係」を要求するが、**方向・正負・作用する側/される側までは要求していない**。そこで最小性を守るため、rootではまず無方向の一関係として扱い、行列の `R[i,j]` と `R[j,i]` は同じ unordered pair の保存上の重複とする。

将来、方向性を入れないと説明できない観測が出た場合だけ、「なぜ方向が必要か」という Why Chain を通して別仮説として比較する。方向を脳や流れのために先に置いてはいけない。

### 最初の変化について

R0 の「関係は変わりうる」を実験として成立させるため、匿名の一つの関係に最小の変化イベントを一度だけ起こす。どの組が選ばれるか、符号、変化量、有限slot数、更新回数、正規化法は**数値レギュレータ**であって物理主張ではない。これらを変えて同じ結果が残るかを必ず比較する。

重要: **この実験は「なぜ最初の変化が可能なのか」をR0より下から説明したふりをしない。** 最初の変化可能性そのものが現在のroot axiom R0である。R0をさらに削れる説明が見つかった場合だけrootを更新する。

### 候補法則の最小文法

自動探索が使える演算は、現在は次の4つだけである。

- `relation_self`: 現在の関係そのもの。
- `relation_composition_2`: 中間の区別を共有する2つの関係の合成。
- `relation_contrast`: すべて同じだった関係から、ある関係が相対的に違うこと。
- `relation_trend`: 前回から今回へどう変わったか。新しい物理場ではなく、R0 の change の履歴差分。

どの組合せが正しいかは**与えない**。小さい候補法則を大量に比較し、有限サイズ・正規化・最初の匿名イベントを変えても残るものを優先する。演算が多い法則には複雑さペナルティをかける。

これら4演算さえ「宇宙の真の法則」とは主張しない。R0 だけから作れる現在の最小候補文法であり、不要な演算は反証で捨てる。`relation_trend` が有利になりすぎる場合は「暗黙に記憶装置を置いていないか」をRoot Criticが問い直す。

## Root Integrity — 計算の足場を物理と数えない

rawな関係行列をそのまま読むと、Pure Genesis自身が簡単に自己欺瞞できる。そのため `ai_lab.dream.root_integrity` を必須で通す。

### 1. slot番号を個体と数えない

上述の permutation quotient で、ラベルを入れ替えても同じ関係profileは同一classとして扱う。

### 2. 最初から用意した完全なrelation canvasを「閉路が創発した」と数えない

計算上は全匿名slot間の関係値を保存できる行列を持つ。この**保存キャンバスの完全グラフ性そのものは創発ではない**。

閉路候補は、root event後に生じたラベル不変の区別class間で、関係contrastから新しく閉じた関係ができた場合だけ測る。複数の相対thresholdで残るものだけを強い候補にする。これもまだ物理空間・幾何学を意味しない。

### 3. 全体符号反転を物理的な振動と数えない

R0 は正負・電荷・極性をまだ与えていない。したがって `R -> -R -> R` のような全体符号反転だけなら、現時点では**表現上の別名（gauge alias）**として同一視する。

「+と-が物理的に違う」と言うには、将来それ自体の Why Chain と反証証拠が必要である。

### 4. update stepの2周期を「周波数」と呼ばない

離散update stepは計算手順であって、まだ物理時間を生成していない。step 2, 4, 8などの反復は探索用の診断として保存しても、**物理周波数の証拠としてpriorityを上げない**。

## 後から測るもの

自動実験は、開始時には与えず、発展後にだけ次を測る。

- R0の最初の差が増幅・持続したか。
- ラベルを消しても新しい区別classが増えたか。
- global signを同一視しても関係変化が残るか。
- root eventの直後には無かった閉じた関係が、区別class間に後から生じたか。
- 関係の有効ランクが変わるか（**まだ物理次元とは呼ばない**）。
- 一時的な介入を取り除いた後も履歴差が残るか（**まだ記憶とは呼ばない**）。
- 数値更新上の反復は記録するが、**物理周波数とは呼ばない**。

空間・物理次元・トーラス・渦・生命・脳は現在のroot実験では**主張しない**。

## 現在の限界を隠さない

関係を実数スカラー行列で表すこと自体は計算表現であり、「宇宙の根源が実数行列である」とは証明していない。有限slot数も宇宙の粒子数ではなく、更新stepも物理時間ではない。正規化も物理法則ではない。

Pure Genesis の目的は、これらの計算上の足場を**物理の前提と取り違えず、結果がそれらに依存しない方向へ一つずつ削っていくこと**である。

## 自動改善

各burstで候補法則を比較し、前burstの有望法則の係数近傍も自動探索する。同時にRoot Integrityが、

- global sign反転だけではないか、
- 新しい区別を本当に増やしたか、
- latent canvasを閉路と誤認していないか、
- `relation_trend` が暗黙の記憶になっていないか、

を問い、次の反証問題を保存する。

**良い結果を作るために監査を弱めることは禁止する。** 自動改善の自由は Why Gate と Root Integrity の内側で使う。

## 既存Aeternaとの関係

既存の g001 / X-pattern / Local Vortex Energy / F-path / Deep-Time / Multi-World は捨てない。それらは「すでに空間・法則などを与えたとき、何が起きるか」を精密に測る下流実験として残す。

v8 では各仮説に `root_relevance` を付け、**観測から先に生まれた未知patternを、人間が先に書いた下流ルートより研究上優先しやすくする**。ただし既存の unexplored / breaker / random の最低枠、科学判定、公式Level、Room昇格条件は変更しない。

合言葉は一つ。

> **「それはなぜあるのか。R0から必要になったのか、それとも人間が置いたのか。」**
