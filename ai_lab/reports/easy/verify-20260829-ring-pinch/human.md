# うえきさんへ — 輪っかは二つにくびれて分かれたか

合言葉：**それは育ったのか、置いたのか？**

メビウスさん経由の問いは、「細胞分裂だ」ではなく、**輪っか（閉じた渦の輪）がくびれて二つになる動き**が、この物理に宿るか、でした。三角に座っている3点や、平面に残った点二つとは仕事が違います。今回は公式の 3D Room を壊さず、**いちばん小さい正直な 3D** で 0 から測りました。生命・細胞分裂・新しい法則の主張はしません。

## 今回 0 からどこまで進んだか

**一つの輪っかがくびれて、別々に追える二つの輪っかになる、は出ていません。**

ただし「輪っかをこの解像度で持てない」でもありません。**円い輪っかを置いた診断**では、測定器は最初から閉じた輪を 1 本と数え、最後まで 1 本のままです。TDGL（公式 Room と同じ緩和の法則）では輪は**縮む**。GPE（煙の輪の既知の白）では輪は**ほぼ同じ大きさの 1 本**のままです。どちらも 1→2 ではありません。

白（何もない揺らぎ）から育てた 32³ では、閉じた孤立リングは出ず、公式 64³ Room は**たくさんの渦線の絡まり**（欠陥の印 241 / 173 / 117）で終わっています。絡まりの再結合は、輪が一つから二つへくびれる動きとは別の仕事です。

## 順番に何が起きて、いま何をしているか

### 公式の 3D Room（記録を読む。64³ は再計算していない）

`room-g001-a` は、一様＋小さな雑音から **t=0 で途中操作なし**。到達は公式 Level 2（渦線）。Level 3（動き・再結合）は candidate＝まだ門を通していない。終端の欠陥数は seed ごとに 241・173・117。これは**一本の輪**ではなく、線がたくさんある状態です。表示用の動画は 20³ に間引いた色の箱で、物理の生データではありません。

64³・700 歩を今回もう一度回すのは、この確認の大きさに対して重いので回していません。代わりに同じ法則を **32³（local-3d。正式 Room ではない）** で 0 から回し、閉ループ測定器をかけました。

### 育った（置いていない）— 32³ TDGL、seed 0 と 1

seed 0：白いざらざらから始まり、冷却のあと振幅が育ち、終端で xy 面の巻きの印が 76。閉じた**バルクの輪**は一度も 0 本超えない。開いた道（箱の縁まで行く線。測定器は周期の継ぎ目を閉じない）が 20〜30。場は本物の 3D（z 方向にちゃんと変化）。スライスの絵には暗い穴がいくつか見える。**それは輪が二つに分かれた絵ではない。線が面を刺した点**です。

seed 1：同じ白から、終端はほとんど一様（平均の大きさ 0.996、いちばん小さいところでも 0.981、巻きの印 0）。32³ の小さな箱では、線が対で消えて残らないことがあります。ヒートマップはコントラストをいっぱいに伸ばすので、**ほぼ平坦な場でも「暗い点」に見えます。それは渦ではありません。**

### 置いた診断 — 円い渦リング 1 本（くびれの場所は置いていない）

測定器の能力確認です。完成したトーラス世界を「育った」とは言いません。

- **TDGL 32³、半径 8**：最初の xy 断面は、黄色い地に**暗い円**が 1 本。同じ時刻の xz 断面は**暗い点二つ**。これは輪が子午面を二回刺している絵であって、輪が二つある絵ではありません。閉ループ数は 1。時間とともに半径 8.5 → 5.4 へ縮む。途中で測定器が 0 本と拾うコマがありますが、それは輪が格子面に沿ってかすめるときの欠測で、直後にまた 1 本に戻る。最後も 1 本。2 本には一度もならない。
- **GPE 32³、半径 7**（計算は FFT の近道。起き方の忠実さは局所 TDGL より下）：既知の e003 と同じ種類。閉ループはほぼ 1 本のまま。半径はほぼ 7。1→2 はない。終端の絵は音波や境界のシートで汚れるが、それは置いた輪の既知の床です。

芯の太さはだいたい 1 マスで、3D の目安（芯半径あたり 8 マス）より粗いです。粗い輪は持てる。くびれて二つ、は出ていない。

### 仕事の分け方（混ぜない）

| 仕事 | 今回 |

| 三角に座る 3 点 | PR 133。今回は見ていない |
| 平面に残った点二つ | 輪の断面、または ± の対。輪の分裂ではない |
| 輪がくびれて 1→2 | **出ていない** |
| F7（関係網が分かれる） | 細胞分裂ではない。今回の門でもない |

見たレーンは **振幅の穴＋巻き（渦芯）** です。明るい塊が裂けるレーンではありません。

## 次に何をやりたいか

- **A（推奨）** — 置いた円リングは 1 本のまま縮む／進む、が分かった。次に手を出すなら、**白から孤立した 1 本の輪が育つか**を、公式 64³ の生の場に閉ループ測定器をかける（今回は要約と 32³ だけ）。64³ の絡まりの中に、たまたま 1→2 があるかは未測。あっても細胞分裂ではない。
- **B** — 芯をちゃんと解像する細かい格子で、置いた円リングがまだ 1 本のままか。粗いから分裂しなかった、を否定するため。分裂の形は置かない。
- **C** — 三角（座る）と輪のピンチ（1→2 の動き）を、測度の名前のまま別カードで残す。混ぜない。

推奨は **A**。今回の天井は「円い輪は置けるし追える。白から一本の輪がくびれて二つ、は 32³ では出ていない。公式 64³ は絡まり」です。神経が足りなかったのではなく、測った範囲ではその動きが宿っていない、という地図です。
