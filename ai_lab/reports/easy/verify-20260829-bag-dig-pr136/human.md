## 2. まず理屈のほう（「置いたから」ではない説明）

この白の式は、ひとことでいうと「**部屋のスイッチを入れると、振幅が決まった高さまで立ち上がる**」というものです。

```
d(ψ)/dt = ε·ψ − |ψ|²·ψ + 拡散
```

スイッチ ε が入ったあと、振幅 |ψ| が落ち着ける「くぼみ」は **ひとつだけ**、`|ψ| = √ε` のところです。
振幅ゼロ（＝外）は、くぼみではありません。**山のてっぺん**です。

これが全部の理由です。

- 山のてっぺんには、何も座っていられません。だから「外」は場所として存在できない。
- 部屋のどの点も、まわりと関係なく、同じひとつのくぼみへ滑り落ちます。
  だから黄色い地面は「ひとつの塊が育った」のではなく、**部屋ぜんぶが同時に同じ高さになった**だけです。
- 振幅がへこんだところがあっても、まわりが埋めます（拡散）。へこみは縮んで消えます。
- 消えずに残るへこみは、**位相がぐるっと一周してしまっている**ところだけ。そこは真ん中を
  ゼロにしないと辻褄が合わないので、穴として残ります。
  つまり **生き残る低いところ＝穴**。袋の反対です。穴は「外が突き抜けている」しるしです。

もうひとつ大事なこと。**この式には「総量が変わらない」という決まりがありません。**
だから「部屋の半分は低いままでいなさい」と縛るものが何もない。片方の側が全部を食べてよい。

この事実は、じつはリポジトリの中にすでに書かれていました。
`genesis/models/mass_conserved_3d.py` のヘッダにこうあります（要約）——
「保存則がない白では『＋』の状態が侵入して部屋を埋めてしまう。総量が保存されていれば
その侵入は禁じられる」。今回測ったのは、まさにその「侵入して埋めてしまう」ほうの白でした。

### 結果（正直に）

**32 回まわして、ぜんぶ袋は出ませんでした。一コマも。**

- 「皮のある一個」と数えられたコマ：**0**
- 5 コマ続いた袋：**0**
- 終わりの黄色い地面の割合：**0.992 〜 1.000**（つまり部屋ぜんぶ）

細かく見ると：

- **ノイズを粗くしても、細かくしても** 終わりは同じでした。粗いと穴が少し減るだけ。
- **速く冷やすと穴が増え、ゆっくり冷やすと穴が減る**。でも黄色い地面が部屋を埋めるのは同じ。
  つまり冷やし方は「穴を何個残すか」を決めるだけで、「袋を作るか」は決めません。
- **スイッチを入れなければ（ε = −1）**、部屋は真っ暗のまま終わります（振幅 1.4e−17）。
  これは「ぜんぶ外」です。中がありません。
  **ε は「ぜんぶ外」か「ぜんぶ中」かを選ぶつまみで、「中と外が隣り合う」という目盛りが無い。**
  これが今回いちばんはっきり見えたことです。
- **浅い部屋（ε = 0.25）**だけ、終わりのコマで外が 19.5% 残っていました。
  でもそれは**まだ登っている途中**だっただけでした。長く（t=408 まで）回したら、
  やはり 1.000（部屋ぜんぶ）になりました。ここは正直に潰しておきました。

### 「外が残る」瞬間は、あるにはある

振幅が育っている**さいちゅう**だけ、外（低いところ）が半分くらいあります（`fig02`）。
32 回中 21 回でそういうコマが見つかりました。でもそれは
**ひとつの地面が広がっていく途中の絵**であって、**二つの地面が隣り合って座っている絵ではありません。**
だから袋の合格にはしていません（そもそも合格条件に入れていません）。

最後の証拠が `fig09` の棒グラフです。終わりの振幅を並べると、**山はいつもひとつ**。
袋には、**居座る山が二つ**必要です。

## 8. 次の一手（**一つだけ**）

> **すでにリポジトリにある g003 Model H（`genesis/models/model_h.py`、公式 room-g003-a）に、
> PR #135 の凍結した袋判定を、緩めずにそのままかける。
> 変えるのは、部屋の気候としてあらかじめ宣言する「混ぜ物の割合」`mean_phi` を 0 から外すことだけ。**

なぜこれか：

- **新しい場を足しません。** この場はもう部屋にあり、公式 Room にもなっています。
- **形を置きません。** `mean_phi` は「部屋にどれだけ入っているか」という**一様な一個の数字**です。
  円でも、膜でも、場所でも、大きさでもありません。
- 今日いちばんはっきりしたのは「**地がひとつしかない白では、外が座れない**」でした。
  g003 は**地が二つあり、総量が保存されている**——今日欠けていたものが両方そろっている、
  唯一の、すでにある白です。
- mean_phi を 0 から外すと（片方の地が少数派になると）、少数派は**塊としてまとまるしかなくなる**。
  それが「境のある一個」になるのか、それとも粒がたくさん出るだけなのかは、**測っていないので分かりません。**
  出なければ、それが所見です。

**先に文書で問うておくこと（実装の前に）：** `mean_phi` を 0 から外したとき、もし塊が出たとして、
その塊の**大きさ**は混ぜ物の割合が決めています。だから正直な言い方は
「**境のある塊が育った**」までで、「大きさまで無から出た」とは言えません。
これは「それは育ったのか、置いたのか？」に半分だけ引っかかります。
半分引っかかることを、先に書いておきます。

三角に戻る提案ではありません。輪のくびれでもありません。穴を数える提案でもありません。
