# うえきさんへ — 空に近いところから、三角の3渦は育ったか

合言葉：**それは育ったのか、置いたのか？**

この回は新しい物理を足していません。報告 `dream-20260829-0520` が言っていた「同じ run で一時的な3渦三角まで行った」と、「場のコントラストがはっきりする（amp_std が増える）＝何かが生まれた」を、リポジトリの測定器で **0 からやり直して** 見ました。

## 今回 0 からどこまで進んだか

**公式の幾何検出器は、引用された条件で F4（一時的な三角）までを再検出した。** 終端の場の指紋も、報告に書いてあった値と一致した。三角形は初期条件に置いていない。

**ただし、人が「空の場に3つの渦が三角に座っている」と見る絵には、なっていない。** 検出器が三角と言った瞬間、場の平均の大きさはまだ約 2.6×10⁻⁸ で、巻き数の印は 45 個ある。3つだけが残った物体ではない。

バランスが崩れる段階（F5）と、関係網が分かれる段階（F7）は、今回も出ていない。生命・細胞分裂・新しい法則の主張はしない。これは 2D の短い確認計算であり、正式な 3D Room ではない。

## 順番に何が起きて、いま何をしているか

引用した条件は **family=white, seed=517111**。ほぼ何もない白い揺らぎ（大きさ約 3×10⁻⁵）から、時刻 0 で開始。三角も渦も置いていない。

1. **最初** — 画素ごとの細かい雑音。見た目は構造なし。巻き数検出器は、振幅が小さすぎるのに相対的なしきい値で **何百個も** 反応する（これは後で消える雑音巻き）。
2. **冷却の途中（t≈4）** — 検出器が「3点が互いに近く、形が三角らしい」と2枚連続で判定（辺の長さ ≈4, 4.47, 4.47、電荷 +−−）。このとき場はまだほとんどゼロ。ヒートマップはまだざらざら。
3. **冷却の終わり（t≈6.6〜10.5）** — その雑音巻きは減って **0 個** になる。三角も消える。
4. **そのあと（t≈11.8）** — 振幅が急に大きくなり、**新しい渦が何十個も** 核になる（Kibble–Zurek 型）。終端は約 50 個。明るい地に暗い芯がたくさん。三角検出は終端では偽。
5. **F5 / 分裂** — 「ひとつの集まりのままバランスが崩れる」は偽。検出器は後で分裂っぽい印を付けるが、それは早期の3点物体が分かれたという意味ではない。

同じ報告の別候補 **seed=948530** も、検出器は F4。こちらは後半（t≈15.6）に、**すでに何十個もある渦の中の局所3点** として三角が残る。空に3つだけ、ではない。終端の場の指紋は報告値と一致。

**コントラストの話（X-b991d59a4d = amp_std が大きく増える）：**
保存されていた追試条件（white_lowk）を 0 から回すと、t≈11.3 でその指紋が出る。その瞬間 **渦の数は 0→0**。平均の大きさも標準偏差もほぼ同じ倍率で増えていて、相対的な凸凹（amp_cv）はほぼ変わらない。分類は **振幅の全体スケール追跡**。渦が2個現れるのは **その後の別イベント**。終端ははっきりした芯が2つ。三角ではない。

つまり、「コントラストがはっきりする」は、**何かが生まれたことと同じではない**。全体が同じ形のまま大きくなっただけ、ということが実際に起きる。

## 次に何をやりたいか

- **A（推奨）** — 三角判定を「振幅がすでに育ったあとの、少数の持続渦」に限って、同じ seed を見ると F4 は残るか。しきい値は変えない。いまの検出器が何を数えているかの地図。
- **B** — 引用 seed を quick=False（96²・長い時間）で 0 からやり直し、後半の多渦状態が三角へ整理されるかを測る。
- **C** — amp_std:+L の追試を white（物体なし）だけに絞り、渦が出る前のスケール追跡と、渦核が残ったあとの cv 低下を同じ図に残す。

推奨は **A**。検出器の F4 と、人が見る「3つの渦」が同じものかを、まず正直に分ける。
