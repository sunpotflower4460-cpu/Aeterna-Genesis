# MODEL_CONTRACT — 化学系の系譜・組成の持ち越し監査（v0.1）

## 0. 位置付け
- 抽象分子 X, Y, Z, XY, XZ, XYZ（構成単位の数だけで定義）の閉じた、よく混合された反応容器。
- 外部実験者が一定割合を移送し、新鮮な単量体で補う操作（実験プロトコル）。
- 空間構造・膜・細胞・遺伝情報・形質は**含まない**。Genesis の正式な Room でも 3D 創発 Level でもない。
- 「継承」を作るコードは置かない（禁止事項は PRE_REGISTRATION.json の forbidden_by_design）。

## 1. 化学種（構成単位 X, Y, Z の数）
| 種 | (X, Y, Z) |
|---|---|
| X | (1,0,0) |
| Y | (0,1,0) |
| Z | (0,0,1) |
| XY | (1,1,0) |
| XZ | (1,0,1) |
| XYZ | (1,1,1) |

## 2. 反応網（宣言。結果に合わせて変更しない）
- R0: X + Y ⇌ XY
- R1: X + Z ⇌ XZ
- R2: XY + Z ⇌ XYZ
- R3: XZ + Y ⇌ XYZ

化学量論の構成単位保存は T01 で厳密に確認（残差 0）。自己触媒・自己複製・増幅の反応は**含まない**。

## 3. 熱力学（RT = 1、標準濃度 c0 = 1、体積 V = 1）
- 理想希薄溶液、活量 a_i = c_i / c0。
- 標準化学ポテンシャル g = (X 0, Y 0, Z 0, XY −2, XZ −2, XYZ −4)（宣言。平衡定数 K = e² を与えるのみ）。
- μ_i = g_i + ln c_i。G = Σ c_i (g_i + ln c_i − 1)。ΔrG = Σ ν μ = ΔrG0 + ln Q。
- 速度定数：k+ = 1（全反応、宣言）、k− = k+ / K_r。正逆比は熱力学から決まり、乱数で決めない。
- 質量作用の速度式 r = k+ Π a_反応物 − k− Π a_生成物。閉じた系で dG/dt = Σ r ΔrG ≤ 0（T03）。
- Wegscheider 残差 ln(K0 K2) − ln(K1 K3) = 0（T02）。

## 4. 数値
- scipy solve_ivp, BDF, rtol 1e-9, atol 1e-12。負値を 0 に丸めない。負値は報告し、許容 1e-9 を超えたら FAIL。
- 確率的検算（T15）：Gillespie SSA、X + Y ⇌ XY の 1 反応のみ、Ω = 200、300〜500 試行。

## 5. 初期状態（外部準備・宣言。創発ではない）
- 構成単位総量 T = (1, 1, 1)。
- 系列 s（s = 0..23）の第 0 世代の状態：XY, XZ, XYZ の量を rng(10000 + s) から一様分布 [0, 0.3] で引き、残りを単量体で構成単位の総量を合わせる。
- これは「違う過去を持つ試料」を与えるための外部操作であり、変異や形質ではない。

## 6. 移送プロトコル（外部操作。化学反応とは別レイヤー）
- 世代 g の終了時の状態 c_p に対し、割合 f を移送：移送物 f·c_p。
- 新しい容器：移送物 + 単量体 (1 − f)·T（新鮮な材料）。構成単位の総量は T のまま（T05 で確認）。
- 移送操作は**観測器の値を読まない**。親の特徴量を子へコピーする処理はない。
- 混合は外部操作として台帳に記録し、散逸とは扱わない（閉鎖系の dG/dt ≤ 0 は世代内の閉鎖位相だけに適用）。

## 7. 対照群（すべて同じ T・同じ f・同じ τ・同じ系列）
| 腕 | 内容 | 検証の対象 |
|---|---|---|
| L1 | 自分の親の状態を f 移送 | 組成の持ち越しと反応の影響 |
| LR | 親の移送分を単量体に再構成（構成単位は同じ） | 分子状態の持ち越しと単純な材料の持ち越しの区別。構造上 L0 と第 g 世代の開始状態が一致する（T06） |
| L0 | 毎世代、新鮮な単量体のみ（f = 0） | 同じ環境での収束 |
| LN | L1 と同じ移送だが反応速度 0 | 受動的な希釈による持ち越し（基準） |
| LS | 独立な別系列（s + n/2 mod n）の L1 状態を移送 | 親子固有の影響 |

## 8. 観測量（観測器は状態をコピーして読むだけ。T11）
- M1 組成距離：0.5 Σ|c − c'|（絶対量、T = 1 単位）。
- M3 親固有の散らばり：系列ごとの、その世代・腕の平均状態からの距離（系列が統計の単位）。
- M4 移送由来の差：L1 と対応する LR の距離。
- 受動的な期待値：f^g × （第 0 世代の系列ごとの散らばりの平均）。T13 で厳密に成り立つことを確認。
- R 比：M3 の平均 / 受動的期待値（系列で対応づけ）。
- M6 構成単位の総量と複合体の割合。M7 反応の使用量（診断のみ）。

## 9. 判定規則（事前登録。結果を見て変更しない）
- A（単一世代の持ち越し）：g = 1 の M3 の 95% CI 下限 > δ = 0.01。
- C（複数世代の親固有の持続）：g = 5 の M3 の 95% CI 下限 > δ。
- Q2（受動的な持ち越しを超えるか）：g = 1 の R 比の 95% CI が 1 を上回る → EXCESS。下回る → BELOW_PASSIVE。含む → NOT_DISTINGUISHABLE。
- 最終世代の共有オフセット（M4）が正で、親固有の散らばり（M3）が δ 以下 → **単一の定常状態（単一 attractor）による差**。親固有の遺伝とは言わない。
- 雑音床 1e−6 を超えるかの二段目の判定も併記（検出可能性の報告）。
- 継承（Q2 の意味）は、EXCESS かつ親固有の持続（C）が同時に成り立つ場合に限り、「親固有の情報が反応によって世代を超えて残る」とだけ書く。生命・進化とは書かない。
- D（選択可能な継承差）・E（進化可能性）は v0.1 で検証せず NOT_TESTED。

## 10. 解釈の上限
- 検証された結果は、宣言した反応網と初期準備・移送比率の下でのみ成り立つ。
- 組成の持続が見えても、それが情報の継承か、単一の定常状態の影響かは M3 と M4 の区別で判断する。
