## 1. 結論（先に）
1. **Q1（親の組成は子の未来を変えるか）**：一世代だけ変える。反応が速い条件（τ = 0.2、f = 0.1）では、親の組成差の 66%（CI 64–68%）が次世代に残る。τ = 2 では 8%。τ = 20（平衡）では 0。
2. **Q2（単純な持ち越し以上か）**：**いいえ**。残る差は受動的な希釈（f^g）より**小さい**（R 比は全条件で 1 未満、CI の上限が 1 を下回る）。反応は持ち越しを増やさず、むしろ消す。
3. **親固有の持続（C）**：**なし**。親固有の散らばりは、τ = 0.2 で 2 世代、τ = 2 で 1 世代以内に消える。第 5 世代の検出は全条件で不成立。
4. **定常状態の共有オフセット**：τ ≤ 2 で、移送した複合体が単量体だけの系と比べて定常状態を少し変える（τ = 0.2：0.0298、τ = 2：0.0127、f = 0.1）。ただし**親に依らず同じ値**（第 30 世代の系列間の散らばり ≈ 1e−15）。これは親の情報の継承ではなく、プロトコルと反応速度が決める**単一の定常状態（attractor）**による差。
5. **Q3（進化可能性）**：検証していない（NOT_TESTED）。
6. **まとめ**：この反応網とプロトコルの下では、組成の差は世代を超えて親固有の情報として残らない。継承は観測されなかった。これは正当な否定的結果である。

## 2. モデル（MODEL_CONTRACT.md の要約）
- 化学種は構成単位 (X, Y, Z) の数だけで定義（抽象分子）。
- 反応 R0–R3（X+Y⇌XY、X+Z⇌XZ、XY+Z⇌XYZ、XZ+Y⇌XYZ）。構成単位の保存を T01 で厳密に確認（残差 0.0）。
- 熱力学：RT = 1、c0 = 1、V = 1。標準化学ポテンシャル g = (0, 0, 0, −2, −2, −4)（宣言）。K_r = e² を全反応で与える。k+ = 1、k− = k+/K_r（乱数で決めない）。Wegscheider 残差 0.0（T02）。詳細つり合いの確認：長時間の平衡で log 誤差 0.0。
- 閉じた位相の自由エネルギー G = Σ c_i (g_i + ln c_i − 1)。dG/dt = Σ r ΔrG ≤ 0（解析・数値の両方で T03）。formal run の全条件で閉じた位相の最大増加は ≤ 0。
- 数値：solve_ivp BDF、rtol 1e−9、atol 1e−12。クリップなし。T14 の収束：中間許容誤差と最細の差 1.8e−9（許容 1e−6 以下）。

## 3. 初期状態と移送プロトコル（外部操作）
- 初期状態（系列 s = 0..23）：XY, XZ, XYZ の量を rng(10000+s) から一様分布 [0, 0.3] で引き、残りを単量体で構成単位の総量 T = (1,1,1) に合わせる。**外部の準備であり、変異や形質ではない。**
- 移送：世代の終わりに状態の割合 f を取り、新鮮な単量体（構成単位 (1−f)T）で補う。構成単位の総量は全ての容器で T のまま（残差 0.0、T05）。移送は観測器の値を読まず、子に親の特徴を書き込まない。
- 世代の長さ τ ∈ {0.2, 2, 20}（単位 1/k+）、f ∈ {0.10（主条件）, 0.01（比較）}、世代数 30、系列数 24。

## 14. 限界（LIMITATIONS.md を参照）
- 抽象分子と宣言された反応網。実在の化学の定量再現ではない。
- よく混合された閉鎖容器。空間構造・膜・細胞はない。
- 自己触媒・増幅・自己複製はない。単一の定常状態しか持たない反応網なので、親固有の情報を保持する機構（多安定性やヒステリシス）が無い。
- 文献は二次情報のみ確認。
- 進化可能性（Q3）、選択、変異は未検証。

## 15. 次の実験への示唆（提案。今回は実装しない）
1. 親固有の世代間の持続を問うには、**複数の定常状態（多安定性）**を持つ反応網が必要になる。ただし、その網を探して選ぶ行為は、結果を見て合格基準を調整することになりかねない。事前に網と判定を固定して、v0.2 として別に登録すること。
2. 移送比率 f と世代の長さ τ を、「受動的基準を超える持続」を探す格子として使う。今回は f と τ の両方で受動的基準を超えなかった。
3. Q3 は、選択可能な差と世代間の増減を入れた別の監査にする。化学だけでは答えられない。

## 16. 主張の上限
- 本監査が言えること：宣言した抽象反応網と移送プロトコルの下で、組成の差は一世代以内に大部分が消え、世代を超えた親固有の持続は検出されなかった。定常状態のずれは親に依らない。
- 言えないこと：生命の発生、細胞分裂、遺伝情報の発生、進化の成立、GARD や Vasas らの論争の決着、Genesis の創発 Level の上昇。
