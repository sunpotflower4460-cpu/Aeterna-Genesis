# LIMITATIONS — 限界（v0.1）

1. 抽象分子・抽象反応網。実在の化学系の定量再現ではない。
2. よく混合された閉鎖容器。空間構造・膜・細胞はない。3D 創発 Level への寄与はない。
3. 自己触媒・自己複製・増幅の反応はない。移送で増える量は、外部操作が決める。
4. 初期準備と移送比率は外部から与える。その値を変えると結論が変わる（感度は結果に明記する）。
5. 決定論的な ODE なので、系列の差は初期準備だけから生まれる。確率的な揺らぎは SSA 検算（T15、単一反応）でのみ扱う。
6. δ = 0.01 は宣言した最小効果量。雑音床 1e-6 も併記する。
7. 文献は二次的な要約のみ確認。全文は未確認。
8. 進化可能性（Q3）、選択、変異、適応は検証していない。
9. 既存の Genesis 実験（e038, e043 など）の記録に不整合がある（e038 の AUDIT「頑健」と robustness.json の false、e043 の要約値と universe.json の不一致）。本監査では変更せず、比較の注意として記録する。
