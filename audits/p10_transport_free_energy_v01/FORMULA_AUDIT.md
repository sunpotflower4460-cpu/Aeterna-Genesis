## 1. F0 §2 に書かれた式（そのまま転記・変更なし）

```
F[φ,{c_i}] = ∫ [ a/4 (φ²−1)² + κ(m)/2 |∇φ|² + Σ_i χ_i φ c_i ] dV          (F-0)
μ_φ = a φ(φ²−1) − div(κ(m) ∇φ) + Σ_i χ_i c_i                                (F-1)
∂_t φ + u·∇φ = M_φ ∇²μ_φ                                                       (F-2)
∂_t c_i + u·∇c_i = div(D(φ) ∇c_i) + (源・反応・外部流入)                     (F-3)
```

F-3 の各化学種（f, m, w）の具体形は F0 にそのまま書かれている。`f` と `w` には `∂_t f = div(D∇f) + J_f^ext − k1 R f`、`∂_t m = div(D∇m) + k1 R f − k2 m`、`∂_t w = div(D∇w) + k2 m − k_out w`。**いずれも輸送項は `div(D(φ)∇c)` のみで、`χ_i` も `μ_i` も含まない。**

## 2. 自由エネルギーから化学ポテンシャルを導出（独立導出）

### 2.1 参照自由エネルギー（監査用の明示モデル）

F0 の `F` には濃度勾配を駆動する項がないため、理想混合項を加えた参照モデルを定義する（F0 は変更しない）。

```
F_ref[c|φ] = ∫ Σ_i [ RT c_i (ln(c_i/c_ref) − 1) + χ_i φ c_i ] dV             (R-0)
```

### 2.2 変分

```
μ_i = δF_ref/δc_i = RT ln(c_i/c_ref) + RT − RT + χ_i φ
    = RT ln(c_i/c_ref) + χ_i φ                                                (R-1)
```

- 理想混合項の変分は `RT ln(c/c_ref)`（`RT` の項は打ち消す）。
- `χ_i φ c_i` の変分は `χ_i φ`。
- 単位：`c` は数密度、`RT` はエネルギー、`χ_i φ` はエネルギー。`μ` はエネルギー（1 粒子あたり）。無次元化は `RT = 1`, `c_ref = 1`, `L = 1` とし、`χ_i/RT = β_i` と書く。

### 2.3 F0 の `F` のみからの化学ポテンシャル

F0 の `F` だけから `δF/δc_i` を取ると `χ_i φ` のみになり、`∇μ_i = χ_i ∇φ` で**濃度勾配の項が消える**。したがって F0 の `F` からは F-3 の `div(D∇c)`（濃度勾配による Fick 流）は**出てこない**（D-2）。Fick 流は `RT c ln c` 項の変分（R-1）に由来する。

### 2.4 流束（μ 勾配による保存流束）

化学種は保存される（∂_t c = −div J）。移動度 `M_i(c)` を用いて

```
J_i = −M_i c_i ∇μ_i                                                             (R-2)
```

と置く。`∇μ_i = RT ∇c_i / c_i + χ_i ∇φ` より

```
J_i = −M_i (RT ∇c_i + χ_i c_i ∇φ)
```

**共通の拡散係数を採用**：`M_i = D(φ)/RT`（種に依らない）とすると

```
J_i = −D(φ) [ ∇c_i + (χ_i/RT) c_i ∇φ ]  =  −D(φ) [ ∇c_i + β_i c_i ∇φ ]        (R-3)
```

これが依頼の 4.1 の式であり、`RT` の無次元化は `RT = 1` で `β_i = χ_i`。`D(φ)` は**移動度**（速さ）、`β_i` は**分配**（平衡の形）の役割を持ち、種別の差は `β_i` にだけ入る。種別固有の `D_i(φ)` は導入していない。

`div J_i = 0` の定常（無流束）は `J_i = 0` ⇔ `∇μ_i = 0`（c>0 のとき）⇔ `RT ln c_i + χ_i φ = const` ⇔

```
c_i(x) = C_i exp(−β_i φ(x))                                                    (R-4)
```

`C_i` は全質量で決まる。**D(φ) は定常値を変えない**（移動度は速さのみ）。

### 2.5 F0 の輸送式との比較（D-1）

F0 の輸送式（F-3 の拡散項）は

```
J_i^{F0} = −D(φ) ∇c_i                                                          (F0-flux)
```

であり、式 (R-3) との差は **`−D(φ) β_i c_i ∇φ`** だけである。

- `β_i = 0` では両者は一致する（非選択の対照）。
- `β_i ≠ 0` では F0 の式は分配を**駆動しない**。`∇c = 0` が定常であり、その定常は一様場（R-4 の `β=0` の場合と同じ）。すなわち**F0 に書かれた流束式のみからは、自由エネルギー由来の種別分配は導けない**（T2A で数値的に確認）。

ただし「P10 で種別差が絶対に出ない」とは言えない。F0 が明示していないだけで、R-3 を仮定すれば分配は出る。これは §7 の「未記載の仮定」に該当する。

## 3. φ の化学ポテンシャル（F-1）の検算

### 3.1 変分

`F` の φ 依存部分の変分：

- `a/4 (φ²−1)²` → `a φ (φ²−1)`。
- `κ(m(x))/2 |∇φ|²` → `−div(κ ∇φ)`。**κ が空間変化しても** `−div(κ∇φ) = −κ∇²φ − (∇κ)·∇φ` であり、`−κ∇²φ` は**誤り**（κ が一定のときのみ一致）。F-1 の `div(κ∇φ)` は正しい。
- `χ_i φ c_i` → `χ_i c_i`。

よって F-1 は `F` と整合する。

### 3.2 対称性（Maxwell 関係）

`∂μ_i/∂φ = χ_i` かつ `∂μ_φ/∂c_i = χ_i`。混合二階偏微分が一致するので、`F` の変分導出と整合する。

### 3.3 離散版（1-D 検算で使う形）

`dx` のセル、面 `j+1/2` の κ を面平均 `κ_{j+1/2}`、`Δ_{j+1/2} = φ_{j+1} − φ_j` とすると、離散 `F_φ` の変分は

```
∂F_φ/∂φ_j = dx · [ a φ_j(φ_j²−1) − (κ_{j+1/2} Δ_{j+1/2} − κ_{j−1/2} Δ_{j−1/2})/dx² + χ Σ c ]
```

（T1 で有限差分と照合する。）

## 4. m の化学ポテンシャルと界面項（D-3）

`m` が `κ(m)` を通じて界面エネルギーに寄与するなら、`F` の `m` 変分は

```
μ_m^{(F)} = δF/δm = (κ'(m)/2) |∇φ|²  （＋ RT ln(m/c_ref) + χ_m φ、m を化学種として扱う場合）
```

である。`κ(m) = κ0 (1 − α m)` とすると `κ' = −κ0 α < 0`。界面（|∇φ| 大）では `μ_m^{(F)}` が**負**になり、`m` は界面へ向かう駆動を受ける（エネルギーを下げるため）。

- F0 §2 の `m` 輸送式（F-3 の `m` 行）にはこの項が無い。
- F0 §4 の「m → 界面（上向き）」フィードバックを式として成立させるには、`m` の流束に `−M_m c_m ∇μ_m^{(F)}` を入れる必要がある。**今回は実装しない**（φ 固定・P10 未実装のため）。
- 対照の意味：F0 の主張が「m が界面物理を変える」なら、その経路は `F` の `κ(m)` 項を通じて**エネルギー的に**入るべきで、F0 のように `κ(m)` を界面に書くだけでは輸送には現れない（不一致）。

## 5. 界面張力 γ(m) と線形近似（D-4）

F0 §2（同節の `σ_M`）は `γ(m) = γ0 − Γ_m m` を使う。F0 の `κ(m)` と `a` から導くと、平衡の 1-D 界面（`φ' = √(2W/κ)`, `W = a/4 (φ²−1)²`）の表面張力は

```
σ = ∫ κ φ'² dx = ∫_{−1}^{1} √(2κW) dφ = (2/3) √(2 a κ)  ∝ √κ(m)
```

である。`κ(m) = κ0(1−αm)` なら `σ(m) = σ0 √(1−αm) ≈ σ0 (1 − αm/2)`。よって線形 `γ(m)` は **αm ≪ 1 の一次近似**であり、F0 は近似であることを明記すべき。Marangoni 応力 `σ_M` の導出（Korteweg 応力との対応）は今回検算していない。

## 6. 反応と熱力学整合性（D-5）

- F0 の `f→m→w` は `k1 R f`、`k2 m`、`k_out w` の**不可逆一次反応**である。
- `ΔG_rxn = Σ_i ν_i μ_i` と `A = −ΔG`（反応親和度）は F0 §4 で定義されているが、不可逆反応では `A` が有限のとき反応流量と `A` の関係（例：`r = r_+ − r_−`、`r_± ∝ exp(±A/2RT)`）が無く、エントロピー生成 `Σ r A/T ≥ 0` を満たす形にならない。
- 元素保存：`f`, `m`, `w` の化学量論（`f→m→w` の各段の元素組成）が F0 に明示されていない。
- **未解決**。今回は反応を実装せず、輸送のみを扱う。

## 8. 保存則・エネルギー散逸の式（R-3 を仮定したとき）

### 8.1 質量保存

`J` が面ごとに共有（隣接セルで符号反転）されるなら、`Σ_j c_j dx` は離散でも厳密に保存される（境界 `J=0`）。

### 8.2 自由エネルギー（F_ref）の時間変化

`∂_t c_j = −(J_{j+1/2} − J_{j−1/2})/dx`、`F_ref = dx Σ_j f(c_j, φ_j)`、`∂f/∂c = μ` より

```
dF_ref/dt = Σ_faces J_{j+1/2} (μ_{j+1} − μ_j)
          = − Σ_faces M_face c_face (Δμ_{j+1/2})² / dx   ≤ 0                     (E-1)
```

（`M_face c_face > 0`）。これは**離散でも厳密**な散逸恒等式であり、T8 で数値的に照合する。

### 8.3 F0-literal 流束（F0-flux）の場合

`J = −D∇c` のとき

```
dF_ref/dt = −∫ D RT |∇c|²/c dx  −  ∫ D χ ∇c·∇φ dx                             (E-2)
```

第 2 項は符号が定まらない。よって **F0 本文の流束のままでは F_ref の単調減少は保証されない**（exploratory T8b で観測する）。
