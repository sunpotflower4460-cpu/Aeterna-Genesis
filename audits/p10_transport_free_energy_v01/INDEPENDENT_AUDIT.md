## 0. 最終の問いへの答え

依頼の問い：「P10 における物質の選択的な輸送は、設計者が望む選択性を直接書き込まなくても、物理的に整合した自由エネルギーと局所輸送法則から説明できるか。」

**限定つきで「はい」。ただし、F0 本文に書かれた式のままでは「いいえ」。**

- **説明できる部分（V 検証で PASS）**：F0 の χ_i φ c_i（分配項）を含む自由エネルギーの変分から導いた化学ポテンシャル `μ_i = RT ln c_i + χ_i φ` を流束に入れると（`J = −D(φ)[∇c + (χ/RT) c ∇φ]`、種に共通の D）、平衡は `c_i ∝ exp(−χ_i φ/RT)` になる。選択性（種間の分配比）は χ_i の差だけから出る。D の値や空間分布を変えても平衡は変わらない（T4・T5・T6）。
- **説明できない部分**：F0 §2 の輸送式 `∂_t c = div(D(φ)∇c)` には χ_i が無い。その式のままでは分配は出ない（T2A：一様に緩和し、分配比 = 1）。さらに、その式は一部の初期条件で F_ref を**増やす**（§J：同じ初期値の山で F_ref が +0.031（β=0.5）、+0.111（β=1.5）増える。μ 流は同じ初期値で −0.078、−0.682 減る）。F0 の選択性の主張は、書かれた式からは導けない。
- **未検証**：非平衡の透過（燃料供給下の通過流束）、界面の自発形成、反応 `f→m→w` の熱力学、`m` の界面項、流体との結合。

## A. 数学的な結論

### A.1 F0 に明示されていること／V0 が補っていること／今回の参照モデルが補ったこと

| 項目 | F0 §2 に明示 | 既存 V0（3D 球）が実装 | 今回の独立参照（本監査） |
|---|---|---|---|
| 自由エネルギー φ 項 `a/4(φ²−1)²`、`κ(m)/2|∇φ|²` | あり | 無し（φ は手置き） | 同じ式を離散化して変分を検算（T1） |
| 分配項 `Σ χ_i φ c_i` | あり | `μ = RT ln c + χφ`（docstring） | 同じ（R-0, R-1） |

| 化学種の輸送 | `div(D(φ)∇c)`、χ 無し（D-1） | `J = −D(∇c + (χ/RT)c∇φ)` | `J = −M c_face Δμ/dx`、`M = D/RT`（R-3 と同じ連続極限） |

| 反応 | 不可逆の質量作用（D-5） | 無し | 無し（対象外） |

### A.2 導出（要点・詳細は FORMULA_AUDIT.md）

1. `F_ref[c|φ] = ∫Σ_i [RT c_i(ln(c_i/c_ref) − 1) + χ_i φ c_i]` の変分：`μ_i = RT ln(c_i/c_ref) + χ_i φ`。
2. `J_i = −M_i c_i ∇μ_i`、`M_i = D(φ)/RT`（種に共通）から `J_i = −D(φ)[∇c_i + (χ_i/RT) c_i ∇φ]`。
3. 無流束の定常は `∇μ = 0`、すなわち `c_i ∝ exp(−χ_i φ/RT)`。D は定常値を変えない（移動度）。
4. 散逸：`dF_ref/dt = −Σ_faces M_face c_face (Δμ)²/dx ≤ 0`（離散でも厳密。T8 で検算）。
5. `μ_φ` の変分：`∂F/∂φ_j = dx·μ_φ,j`（離散でも厳密。T1 で検算）。`−div(κ∇φ)` は κ が空間変化するとき `−κ∇²φ` と異なる（T1 で感度 1.1% を確認）。

### A.3 F0 の書かれた式と導出式の差

`J^{F0} − J^{derived} = +D(φ) β_i c_i ∇φ`（β_i = χ_i/RT）。β_i = 0 で一致する（非選択）。β_i ≠ 0 では F0 の式は分配を駆動しない（一様に緩和する）。よって「F0 本文の流束のみから種別分配は導けない」（依頼 T2 の範囲の結論）。

## D. 未解決の物理（今後の検証項目）

1. **非平衡の透過（最重要）**：燃料の外部供給（J_f^ext）の下で、界面を横切る各種の**定常通過流束**を独立に測る。今回は平衡分配だけで、流束は測っていない。Gate I の「実効透過率」の定義を決めてから測る。
2. **反応と熱力学**：可逆反応、化学量論 ν_i、元素保存、親和度、エントロピー生成 ≥0。D-5 が解けるまで、反応を入れた状態で「散逸が正」を主張できない。
3. **界面の自発形成**：今回 φ を固定した。膜・境界の自発形成は**検証していない**。F-2（∂_tφ = M∇²μ_φ）の数値検算は未実施。
4. **m の界面項と上向き経路（D-3）**：κ'(m) < 0 の界面駆動を輸送式へ入れた場合の平衡・散逸を、固定界面で独立に検算する必要がある。
5. **界面張力の m 依存性（D-4）**：Marangoni 応力 `σ_M` を Korteweg 応力から導けるかを確認する。
6. **流体との結合**：Stokes の射影（FFT 版は global spectral validator であり「中央計算なし」ではない）と、局所 stencil 版での独立検算。
7. **3 次元化**：平面 1-D は、曲率・閉じた器・球の体積比を扱えない。F0 の prereq（G003 の 3D 昇格または dimension-transfer 監査）が先。
8. **χ_i の決め方**：F0 は「分子体積・疎水性に比例」と書くが、式が無い。今回は β を固定値（0.5、−0.5、1.5）で与えた。

## F. AETERNA 本体への示唆（移植・統合はしない）

1. **輸送は「化学ポテンシャルの勾配」で書く。** 種ごとの D_i を置かず、共有の移動度と種ごとの分配（χ_i）の二つに分けると、選択性が後付けにならない（T5・T6 の設計）。
2. **理想混合項を自由エネルギーに必ず入れる。** これが無いと Fick 流が出ず、F と輸送が結べない（D-2）。
3. **散逸の恒等式を数値で確かめる。** 離散の `dF/dt = −Σ M c_face (Δμ)²/dx` は、求積（AMD-2 の教訓：初期の急な変化を粗い格子で解くと 1e−2 の誤差が出る）に敏感。物理の判定の前に、求積の次数を測る。
4. **「書かれた式」と「実装」を分けて監査する。** 今回、V0 は F0 より正しい式を実装していた。文書の方が弱かった。
5. **平衡と緩和を区別する。** 平衡比は D に依らないが、到達時間は D に比例する（T6）。途中の比を平衡差と誤認しない。

## J. 補足（判定の対象外・EXPLORATORY と追加の確認）

`results/SUPPLEMENTARY_NOT_IN_VERDICTS.txt` に全文。要点：

1. **F0 の記載流束（Fick）は F_ref を増やすことがある**（判定なし・確認済み）。同じ初期状態（x=0.7 の山、w=0.1、振幅 0.5、質量 1）で、N=64/128/256 のいずれでも、
   - β=+0.5：Fick で ΔF_ref = **+0.03069**、μ 流で **−0.07796**。
   - β=+1.5：Fick で ΔF_ref = **+0.11061**、μ 流で **−0.68204**。
   - 解像度に依らない（Fick・β=0.5 で N=64/128/256 について +0.03069424、+0.03069423、+0.03069422）。最終の一様状態の F_ref = −1.0 は、初期の −1.0307 より高い。
   - 初期の山の位置を変えると（x=0.3）F は減少する。すなわち符号は初期条件に依る（FORMULA E-2 の「符号が定まらない」と整合）。
   - 解釈：F0 の輸送式は、F_ref（χ 項と理想混合項を含む）の勾配流ではない。F0 は F_ref を明示していないので、「F0 の自由エネルギーが増える」とは言わない。
2. **RK4 の次数が測れない理由**：RK4 の自己収束（dt を半分にした差）は 2.4e−14 と 2.1e−15 で、RK4 自身は十分収束している。BDF の参照解（rtol 1e−11）の誤差 3.5e−11 が床になっている（BDF rtol 1e−9、1e−10、1e−11 と RK4 の差は 1.4e−9、2.2e−10、3.5e−11）。T10c の INCONCLUSIVE はこの床によるもので、RK4 の誤りではない。
3. **判定の余裕**：T1 の species 項の相対誤差は 5.9e−8（閾値 1e−7）、感度は 1.12%（閾値 1%）で、どちらも余裕が小さい。有限差分の丸め誤差と、κ の変化が小さいことによる。
